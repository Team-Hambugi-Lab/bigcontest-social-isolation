# 2026 빅콘테스트: 사회적 고립 예방·대응 AI 에이전트

2026 빅콘테스트 AI데이터활용 분야의 **사회적 고립 예방 및 대응을 위한 AI 에이전트 개발** 프로젝트입니다.

통신 유동인구와 카드 결제 집계 데이터를 활용해 서울 강남구와 강원 춘천시의 사회적 고립 위험 신호를 지역·인구집단 단위로 분석하고, 위험 수준에 맞는 공공·복지 자원을 추천하는 재현 가능한 에이전트 운영 모델을 제안합니다.

## 분석 범위

- 기간: 2025년 7월~12월
- 지역: 서울 강남구, 강원 춘천시
- 분석 단위: 개인이 아닌 비식별 지역·인구집단 집계
- 제공 데이터:
  - SK텔레콤 격자별 성·연령, 시간대, 요일별 유동인구
  - 신한카드 시군구·업종·성별·연령대별 결제금액 및 결제건수
- 목표 흐름: 위험 신호 탐지 → 위험 수준 판단 → 원인 분석 → 대응 방안·복지자원 추천 → 우선 지원 대상 도출

데이터 구조, 결합 기준, 공식 평가 기준과 제출 요건은 [제공 데이터 명세 및 활용 가이드](docs/data-overview.md)를 참고하세요.

사회적 고립 위험 신호의 정의와 검증 원칙은 [사회적 고립 연구 방법론](docs/methodology/README.md)을 참고하세요.

## 데이터 준비

원본 파일은 Git으로 추적하지 않으며 로컬 `data/raw/`에 둡니다.

```text
data/raw/
├── 2026 빅콘테스트 주제설명자료(1008)v1_AI데이터 활용 분야.pdf
├── 2026빅콘테스트_sk통신인구_데이터_레이아웃.zip
└── 2026빅콘테스트_신한카드_데이터_레이아웃.zip
```

제공 데이터에는 개인정보와 개별 가맹점을 식별할 수 없는 집계값만 포함됩니다. 집계 데이터만으로 개인의 사회적 고립 여부를 판정하지 않습니다.

## 환경 설정

Python 3.11 이상과 `uv`를 사용합니다.

```bash
uv sync --extra dev
```

GIS 분석이 필요할 때만 선택 의존성을 설치합니다.

```bash
uv sync --extra dev --extra gis
```

## 디렉터리 구조

```text
├── data/
│   ├── raw/           # 원본 데이터
│   ├── interim/       # 중간 처리 데이터
│   └── processed/     # 최종 분석 데이터
├── docs/              # 데이터 명세와 계획 문서
├── notebooks/         # 탐색 분석과 실험
├── reports/           # 분석 보고서와 제출 산출물
├── src/
│   ├── features/      # 피처 생성
│   ├── modeling/      # 모델 학습
│   └── evaluation/    # 평가
└── tests/             # 테스트
```

## 검증

```bash
uv run ruff check src/ tests/
uv run ruff format --check src/ tests/
uv run pytest tests/ -v
```

## 분석 원칙

- 데이터에서 확인되지 않은 결론은 사실로 단정하지 않습니다.
- 데이터 분할 기준과 난수 시드를 기록합니다.
- 전처리기는 학습 데이터에서만 학습하고 시계열 피처는 미래 값을 참조하지 않습니다.
- 해석 가능하고 재현 가능한 기준 모델부터 검증합니다.
- 외부 데이터는 무료 공개 데이터만 사용하고 출처·수집 방법·원본을 기록합니다.
- 합성 데이터와 LLM을 사용하면 생성·활용 방법과 한계를 문서화합니다.
