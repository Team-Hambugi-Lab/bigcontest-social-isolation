## 테마 정의

> 테마 구조는 CDC/ATSDR SVI(테마별 백분위 + 플래그)를 차용했고, 두 테마의 내용(고령 독거 / 중장년 남성 독거)은 선행연구가 구분하는 두 위험 집단(노인 척도 LSNS·Steptoe vs 복지부 고독사 실태조사 50~60대 남성)에 맞춰 **본 연구가 정의**한 것이다. 차원 배정은 우리 데이터의 PCA(고령 축·중장년 남성 축 분리)와 두 테마 상위 20%가 절반만 겹친다는 결과에 근거한다. 특정 선행연구의 테마를 그대로 가져온 것이 아니다.

| 테마 | 차원 | 정의 |
| --- | --- | --- |
| A 고령 독거 | solo50 | 1인가구율 × 50세+ 비율 (1인가구×연령 교차표 대용) |
| | old | 65세+ 비율 — 노년부양비·노령화지수에서 역산 (결측 없음) |
| | oldho | 1989년 이전 주택 비율 × 비아파트(단독·다세대·연립) 비율 |
| B 중장년 독거·주거취약 | male_solo | 50~64세 남성 비율 × 1인가구율 |
| | housv | (비주거용 건물내 주택 + 20㎡ 이하) / 총거처 |
| | other50 | 주택이외 거처 비율 × 50세+ 비율 (고시원 대리; 오피스텔=청년 가정) |

결측: 카운트 변수 비결측 최솟값이 5 → 5 미만 소량 비공개 → 0 대치 (2 대치 시 Spearman 0.986).

## 알려진 한계

1. solo50·male_solo 모두 1인가구율의 곱이라 "1인가구 많고 중장년/고령도 많은 곳"을 독거로 읽음. 주민등록 1인세대 성·연령 자료 확보 시 교체.
2. 고령 임대단지 서명은 SGIS 패턴 기반 추정. 외부 단지 현황 조인 전까지 라벨은 잠정.
3. other50은 고시원 대리변수. 고시원 현황 공공데이터 확보 시 교체.
4. 보류·혼합지 임계값(1, 5)은 선행연구 수치 근거 없음 — 팀 결정.
5. 종합 등급은 테마 백분위 평균(합의). 한쪽 테마만 높은 집계구는 등급이 4로 내려갈 수 있으나 `type_label`의 A형·B형으로 잡힌다 — 에이전트는 등급과 라벨을 함께 읽을 것.


## 현재 입력 계약과 역할

태은의 후속 정정에 따라 기존 v3 열을 사용한다. 위치는 `TOT_OA_CD`·`ADM_CD`·`REGION`, 우선순위는 `grade`, 유형은 `type_label`, 보류·혼합지는 `hold`·`hold_reason`·`mixed`, 가구 가중치는 `hh_total`이다. 별도 대문자 계약 열이나 VERSION 열은 필수 요청이 아니다. 행정동 가구 수 가중 집계는 에이전트 쪽에서 수행한다.

v3.2는 `rental_est`를 추가하고 `type_label`의 고령 임대단지형 값을 제거했다. 에이전트는 4등급을 포함해 테마 A·B 백분위 80 이상 여부와 유형을 함께 읽는다. 지역 값은 개인 위험 등급을 올리는 근거로 쓰지 않는다.

## 제공 v3.2에 남아 있는 오류와 해석 주의

1. **고령 비율 역산 예외:** 노년부양비 또는 노령화지수가 0이면 `old=0`을 출력한다. 수서동 집계구 `11230750010301`은 공개된 65세 이상 연령별 합이 226명인데 이 예외로 `old=0`·3등급·일반이 된다. 이 오류는 제공 v3.2에도 남아 있다. 노령화지수 0을 고령 인구 없음으로 해석하지 않는다.
2. **보류 사유명:** `거주없음` 35개 중 5개에는 인구 합계 6,683명이 기록돼 있다. 그중 2개는 일반가구가 있으나 주택이외 거처가 결측이고, 3개는 인구 양수·일반가구 0이다. 실제 무거주로 해석하면 안 되며 후속 수정에서 사유를 구분해야 한다.
3. **총주택 0 처리:** 제공 v3.2는 `p_apt`와 `oldho` 등 주택 기반 비율을 0으로 정의해 차원 수를 유지한다. 이는 모델 규약이며 실제 교차 주택수나 결측의 실측 확인을 의미하지 않는다.
4. **대리지표:** 독거×연령·노후×주택유형의 곱은 실제 교차 집계가 아니다. 주거취약 분자는 중복될 수 있다. 임대단지·고시원은 외부 자료 확인 전의 추정이다.
5. **표준화 대상:** 차원 계산 가능 1,663행(업무지·집단가구 보류 94행 포함)으로 z-score를 계산하고, 등급 부여 대상 1,569행으로 백분위를 계산한다. 평가 조건 미충족 35행은 두 계산에서 빠지며 행만 보존한다.

계산식·임계값과 제공 CSV는 이번 저장소 경로 정리에서 바꾸지 않았다. 따라서 위 한계가 해결된 최종 분석본으로 표시하지 않는다. 드라이브 업로드 자체와 공유 권한은 별도로 확인해야 한다.
