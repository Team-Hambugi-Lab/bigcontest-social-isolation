## 테마 정의

> 테마 구조는 CDC/ATSDR SVI(테마별 백분위 + 플래그)를 차용했고, 두 테마의 내용(고령 독거 / 중장년 남성 독거)은 선행연구가 구분하는 두 위험 집단(노인 척도 LSNS·Steptoe vs 복지부 고독사 실태조사 50~60대 남성)에 맞춰 **본 연구가 정의**한 것이다. 차원 배정은 우리 데이터의 PCA(고령 축·중장년 남성 축 분리)와 두 테마 상위 20%가 절반만 겹친다는 결과에 근거한다. 특정 선행연구의 테마를 그대로 가져온 것이 아니다.

| 테마 | 차원 | 정의 |
| --- | --- | --- |
| A 고령 독거 | solo50 | 1인가구율 × 50세+ 비율 (1인가구×연령 교차표 대용) |
| | old | 65세+ 비율 — 노년부양비·노령화지수에서 역산 (결측 없음) |
| | oldho | 1989년 이전 주택 비율 × 비아파트(단독·다세대·연립) 비율 |
| B 중장년 독거·주거취약 | male_solo | 50~64세 남성 비율 × 1인가구율 |
| | housv | (비주거용 건물내 주택 + 20㎡ 이하) / 총거처 |
| | other50 | 주택이외 거처 비율 × 50세+ 비율 (고시원 대리; 오피스텔=청년 가정) |

결측: 원본 v3는 카운트 결측을 5 미만 소량 비공개로 가정해 0으로 대치한다. 제공 설명의 “2 대치 시 Spearman 0.986”은 입력 마스터가 없어 이번 업로드 준비에서 재현하지 못했다.

## 제공 결과 CSV에서 확인한 v3 요약 수치

- 보류 91 (업무지 88, 집단가구 3). v2는 291. 혼합지 라벨 200.
- 테마 A·B 상위 20% 겹침: 313 중 157. 테마 점수 상관 0.78 (둘 다 1인가구율을 곱하므로 독립은 아님).
- 고령 임대단지형 22 (강남 17 — 수서동 11230750·일원1동 11230730, 춘천 5). LH·SH 단지 현황으로 확정 필요.
- 종합 상관: solo50 0.95, male_solo 0.91, old 0.58, oldho 0.56, housv 0.40, other50 0.36.

## 알려진 한계

1. solo50·male_solo 모두 1인가구율의 곱이라 "1인가구 많고 중장년/고령도 많은 곳"을 독거로 읽음. 주민등록 1인세대 성·연령 자료 확보 시 교체.
2. 고령 임대단지 서명은 SGIS 패턴 기반 추정. 외부 단지 현황 조인 전까지 라벨은 잠정.
3. other50은 고시원 대리변수. 고시원 현황 공공데이터 확보 시 교체.
4. 보류·혼합지 임계값(1, 5)은 선행연구 수치 근거 없음 — 팀 결정.


## 실행 경로

입력은 `data/processed/master_sgis2024_selected_no_industry_counts.csv`에 두고 아래 명령을 실행한다.

```bash
uv sync --extra dev
uv run python -m src.features.isolation_index_v3
```

노트북은 저장소 루트 또는 `notebooks/` 아래에서 같은 입력을 읽는다. 원본에는 입력이 같은 폴더에 있다는 가정이 있었으나, 공유본은 공통 경로 상수 `PROCESSED_DIR`, `INTERIM_DIR`을 사용한다. 집계구·SGIS 행정동·월 코드는 문자열로 읽는다. 출력은 아래 세 파일이며 Git에서는 추적하지 않는다.

```text
data/interim/isolation_index_v3.csv
data/interim/isolation_index_v3.csvt
data/interim/isolation_index_v3_dictionary.csv
```

CSV는 원본과 같은 35개 열을 유지한다. 열 설명 CSV는 실행 시 생성하며, 동봉된 기존 CSV의 열 설명도 별도 드라이브용 묶음에 제공한다. 인구·일반가구·주택이 모두 양수인 집계구만 계산하므로 제외된 행과 `hold=True`는 다르다. 표준화 z-score에는 보류 행도 들어가며, 테마·종합 백분위는 보류를 제외해 계산한다. `oldho`의 곱셈도 실제 노후×주택유형 교차 주택수를 직접 관측한 값과 구분한다.

## 최신 댓글의 입력 계약과 남은 연결

[#24 에이전트 입력 계약 댓글](https://github.com/Team-Hambugi-Lab/bigcontest-social-isolation/issues/24#issuecomment-6288737784)은 아래 추가 구조를 요청했다. 이번 파일은 제공 v3의 계산과 결과 형식을 공유하며 이 계약을 모두 반영한 완료본은 아니다.

| 요청 | 현재 제공 v3 | 남은 작업 |
|---|---|---|
| `SGG`, `HOUSEHOLDS` | `REGION`, `hh_total`에 대응 값 있음 | 합의한 이름·버전으로 내보내기 |
| `SCORE_A_PCT`, `SCORE_B_PCT`, `GRADE` | 소문자 `theme_A_pct`, `theme_B_pct`, `grade` | 계약 열 이름으로 연결 |
| `FLAG_A`, `FLAG_B` | 백분위는 있으나 별도 플래그 열 없음 | 지역 내 80 이상 여부를 독립 열로 내보내기 |
| `THEME_TYPE` | `type_label` 한 열에 혼합·임대 후보 등도 겹쳐 있음 | A/B/복합/없음으로 별도 분리 |
| `SITE_TYPE` | `hold`, `mixed` 있음 | 주거/혼합/보류 상태를 별도 열로 내보내기 |
| `RENTAL_COMPLEX` | 패턴 기반 임대단지형 후보 | LH·SH 확인 전에는 미확인으로 관리; 확정 여부와 패턴을 분리 |
| `VERSION` | 별도 열 없음 | 버전 열 추가 |
| 행정동 집계·동 이름 | 집계구 결과만 동봉 | SGIS 경계 기준 동 이름 및 가구수 가중 집계본 준비 |

지역 지수 유형과 개인 특징·기관 태그의 매핑은 별도 사전에서 정한다. 지역 신호로 개인 티어를 올리지 않는다. 이 업로드만으로 #24 전체 완료 체크를 하지 않는다.

## 이번 공유에서 확인한 범위

입력 마스터가 동봉되지 않아 전체 분석 재실행은 수행하지 않았다. 제공 CSV의 1,651행×35열, 집계구 유일성, 코드 길이, 보류 91·혼합지 200 등은 파일 자체에서 확인했다. 제공된 원본 CSV·CSVT는 바이트를 유지해 드라이브 공유용으로 보관하며 저장소에는 코드·노트북·이 문서만 게시한다. README_v3_commit.md의 경로·실행 안내는 이 문서에 반영했다. 임대단지형 22개는 외부 단지 자료 확인 전의 후보다.
