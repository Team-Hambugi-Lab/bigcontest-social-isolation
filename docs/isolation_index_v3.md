## 테마 정의

> 테마 구조는 CDC/ATSDR SVI(테마별 백분위 + 플래그)를 차용했고, 두 테마의 내용(고령 독거 / 중장년 남성 독거)은 선행연구가 구분하는 두 위험 집단(노인 척도 LSNS·Steptoe vs 복지부 고독사 실태조사 50~60대 남성)에 맞춰 **본 연구가 정의**한 것이다. 차원 배정은 우리 데이터의 PCA(고령 축·중장년 남성 축 분리)와 두 테마 상위 20%가 절반만 겹친다는 결과에 근거한다. 특정 선행연구의 테마를 그대로 가져온 것이 아니다.

| 테마 | 차원 | 정의 |
| --- | --- | --- |
| A 고령 독거 | solo50 | 1인가구율 × 50세+ 비율 (1인가구×연령 교차표 대용) |
| | old | 65세+ 비율 — 노년부양비·노령화지수에서 역산, 노령화지수 0이면 노년부양비만, 공개 구간 합을 하한으로 |
| | oldho | 1989년 이전 주택 비율 × 비아파트(단독·다세대·연립) 비율 |
| B 중장년 독거·주거취약 | male_solo | 50~64세 남성 비율 × 1인가구율 |
| | housv | (비주거용 건물내 주택 + 20㎡ 이하) / 총거처 |
| | other50 | 주택이외 거처 비율 × 50세+ 비율 (고시원 대리; 오피스텔=청년 가정) |

결측: 카운트 변수 비결측 최솟값이 5 → 5 미만 소량 비공개 → 0 대치.

## 검증 범위 (C 작업, 이슈 #24 후속 7번)

서울시 1인가구 통신정보의 관심집단 비율은 통계모형으로 추정한 값이고, 월별 값은 직전 3개월 평균이다. 따라서 C 작업은 지수의 "정답지 대조"가 아니라 **행동 관련 대조 자료와의 연관 검증**이다. 6개월 자료는 평균 1회로 취급하고(독립 표본 여섯 배가 아님), 월별 결과는 참고로만 둔다. 검증 단위는 행정동 × 성별 × 연령이며, 지수 쪽 행정동 값은 `isolation_index_v3_adm.csv`의 유효 가구 가중평균을 쓴다.

## 알려진 한계

1. solo50·male_solo 모두 1인가구율의 곱이라 "1인가구 많고 중장년/고령도 많은 곳"을 독거로 읽음. 주민등록 1인세대 성·연령 자료 확보 시 교체.
2. 고령 임대단지 서명은 SGIS 패턴 기반 추정. 외부 단지 현황 조인 전까지 라벨은 잠정.
3. other50은 고시원 대리변수. 고시원 현황 공공데이터 확보 시 교체.
4. 보류·혼합지 임계값(1, 5)·관찰 후보 임계값(80)은 선행연구 수치 근거 없음 — 팀 결정.
5. 종합 등급은 테마 백분위 평균(합의). 한쪽 테마만 높은 집계구는 등급이 3~4로 내려갈 수 있으므로 `watch`·`type_label`을 함께 읽을 것.
6. 결측 대치값에 따라 등급·유형이 바뀌는 집계구가 약 1/5 (`unstable_imp2`). 0·2 대치 가정 사이에서 개별 등급 차이는 최대 4단계다. 이 민감도 차이를 실제 오차 범위나 신뢰구간으로 해석하지 않는다.


## 집계·민감도 해석 보충

- 현재 기본 5등급은 314개다. 백분위 경계의 동점으로 등급별 개수가 정확히 같지 않을 수 있다. 결측 2 대치 비교에서 기본 5등급 37곳이 빠지고 38곳이 새로 들어온다.
- 민감도는 비교 결과의 교집합을 고정한 것이다. 기본 차원 계산 대상 1,663개와 2 대치 대상 1,665개로 표준화·순위를 각각 계산하므로, 표준화 기준 모집단까지 고정한 별도 진단과 구분한다.
- `unstable_imp2=False`에는 비교 대상이 아닌 보류 행도 포함된다. 이를 안정성 확인으로 해석하지 않는다. `grade_imp2`도 참고용 대안 결과다.
- 노령화지수 0에서 노년부양비만 사용하는 식은 유년 비중 0 근사다. ai=0만으로 유년 인구가 없거나 모두 소량 비공개임이 확인된 것은 아니다. 기본 모형의 공개 구간 합 하한은 0 대치 기준이며, 2 대치 실험에서는 대치된 연령 구간 합을 사용한다.
- `일반가구없음`은 통계상 일반가구 0이라는 사유다. 요양시설·군부대 등 특정 시설임을 확인한 라벨이 아니다.
- `watch`는 지역 우선 후보 표시다. C 작업의 상관분석은 유효 자료가 있는 강남 22개 동 전체를 기준으로 하며, watch 후보만 추려 검증 대상을 축소하지 않는다.
- 행정동 집계는 제공 v3.3의 기준 구현이다. 가중평균은 보류 아님·점수 유효 행만 사용하고 `share_hh_eval`·`share_hh_hold`를 함께 읽는다. 지역 신호는 개인 위험 티어를 올리는 근거로 쓰지 않는다.
