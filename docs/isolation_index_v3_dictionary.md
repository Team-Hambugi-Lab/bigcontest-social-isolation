## 정의와 값 해석 보충

`p65_method`는 기본 산출 분기이며 모든 분기에 연령 구간 합 하한을 적용한다. ai=0에서 유년 비중을 0으로 근사한다. `unstable_imp2`는 두 결과에 모두 등급이 있는 곳의 민감성이고, False에는 비교하지 못한 보류 행도 포함된다. 집계구의 일반가구 0은 특정 집단시설 확인을 의미하지 않는다.

기본 5등급은 314개이며 결측 2 대치에서 이탈 37·진입 38개다. 등급 차이는 최대 4단계로, ±1로 제한되지 않는다. 이는 대치 가정 사이의 차이이고 실제 오차 범위가 아니다. 표준화 기준 모집단까지 고정한 실험과 공통 평가 대상 비교를 구분한다.

행정동 사전 CSV `data/interim/isolation_index_v3_adm_dictionary.csv`도 실행 시 자동 생성한다. 집계구 사전 CSV와 각각의 결과 파일을 함께 공유한다. 실행 시 생성되는 CSV 사전은 이 보충 정의와 현재 출력의 결측·요약 수치를 반영한다.
