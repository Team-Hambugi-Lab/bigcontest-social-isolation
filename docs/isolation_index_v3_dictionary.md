## 계산·해석 보충

위 값 요약은 제공 CSV 기준이다. `old`는 현재 노년부양비·노령화지수가 모두 양수일 때만 역산하고 그 외 0으로 처리하므로 고령 인구가 있는 행이 0으로 표시되는 예외가 남아 있다. `hold_reason=거주없음`은 실제로 인구·일반가구·총거처 중 어느 하나가 0 이하인 모든 평가 제외 행에 붙는다. 이 35행 중 5행은 인구 양수이므로 무거주로 읽으면 안 된다.

총주택 0인 12행의 주택 기반 비율은 제공 모델에서 0으로 정의한다. `rental_est=False`는 임대단지가 아님을 확인한 값이 아니라 서명 조건 미충족이다. z-score에는 평가 가능한 보류 행이 포함되고 테마·종합 백분위는 보류를 제외한다. 자세한 내용은 [실행 안내와 남은 오류](isolation_index_v3.md)를 참조한다.

저장소 실행 시 생성되는 사전 CSV는 이 예외 처리와 주택 0 처리의 정의를 명시하고, 출력 파일 기준 결측 수와 요약을 갱신한다.
