# 기존 분석의 검증 기록

기록 기준일: 2026-10-09

아래는 2026년 9월 팀 분석에서 나온 **당시 데이터·코드 기준의 결과**다. 현재 브랜치의 최종 위험지수나 사회적 고립의 확정 판정이 아니다. 재사용할 때는 원자료 버전, 공간 결합키와 계산 단위를 먼저 맞춰야 한다. 원본 보고서는 각 항목의 링크에서 확인할 수 있다.

## 합성지수의 내적 일관성

**검증된 관찰(당시 실험).** 카드 집단축의 세 항목을 합친 첫 설계는 Cronbach's α가 −4.219로 나와 폐기했다. 대면 접촉 기회라는 정의에서 도출한 세 지표는 지역×성별×연령대×월 216개 셀에서 α 0.720을 보였다. 별도 민감도 검사에서는 의료 업종을 접촉 기회로 포함하자 α가 0.749에서 0.180으로 떨어졌다. 출처: [2026-09-26 정의 기반 재설계 계획](https://github.com/Team-Hambugi-Lab/bigcontest-social-isolation/blob/5166e5286b1b801f40b9ff9bf21ad15f1e74d302/docs/plans/260926_routeB_design.md).

**프로젝트 기준.** α 0.720은 세 항목이 함께 움직인다는 내부 점검 결과다. 실제 고립 상태와 맞는지에 대한 외부 검증이나 최종 지수 채택을 뜻하지 않는다. 업종 분류를 바꾸면 결과가 달라지므로 분류표와 제외 이유를 지표 정의와 함께 남긴다.

## 지표 방향의 외부 대조

**검증된 관찰(당시 실험).** 행정동 단위로 SGIS 고령 관련 통계와 SK 유동인구 지표를 비교했을 때, 춘천의 `night_share`는 사전 방향 가정과 부합했지만 `wkdy_cv`는 반대 방향을 보였다. 강남에서는 같은 대조가 뚜렷하게 재현되지 않았다. 출처: [2026-09-26 방향성 외부 검증 보고서](https://github.com/Team-Hambugi-Lab/bigcontest-social-isolation/blob/5166e5286b1b801f40b9ff9bf21ad15f1e74d302/reports/260926_external_validation.md).

**프로젝트 기준.** 고령비율과의 상관은 **고립 상태 자체를 검증한 결과가 아니다**. 예상과 반대인 지표는 부호만 뒤집어 채택하지 않고, 관광·주말 방문 등 다른 원인을 점검한 뒤 개념에서 다시 설계한다. 강남과 춘천에 하나의 방향·가중치를 자동 적용하지 않는다.

## 유동인구와 거주인구의 차이

**검증된 관찰(당시 실험).** 같은 외부 검증에서 강남 일부 행정동의 유동인구가 거주인구보다 크게 집계됐다. 이는 방문객과 근무자의 활동이 주민 신호에 섞일 수 있다는 경고다. 출처: [2026-09-26 방향성 외부 검증 보고서](https://github.com/Team-Hambugi-Lab/bigcontest-social-isolation/blob/5166e5286b1b801f40b9ff9bf21ad15f1e74d302/reports/260926_external_validation.md).

**프로젝트 기준.** SK 지표를 거주민 개인의 행동이나 고립 여부로 해석하지 않는다. 지역별 관측 대상의 차이를 확인하고, 강남과 춘천은 각각 지역 내부에서 검증한다.

## 과거 기록을 다시 쓸 때

- **미해결:** 과거 보고서의 일부 집계는 `BLOCK_CD` 접두로 공간 단위를 만들었다. 현재 프로젝트의 공식 집계구 결합키는 14자리 `TOT_OA_CD`이며, `EPSG:5179` 공간조인 기준으로 재확인이 필요하다. 과거 집계구 수나 고위험 후보 수를 현재 결과로 옮기지 않는다.
- **미해결:** 과거 보고서의 입력 파일과 현재 제공 자료가 같은 버전인지 확인되지 않았다. 중복·결측·양자화에 관한 수치를 인용할 때는 원본 파일과 처리 규칙을 다시 대조한다.
- **프로젝트 기준:** 같은 테이블 안에서 만든 비율과 서로 다른 테이블의 총량 비교는 관측 범위를 다르게 점검한다. [연구 프레임의 데이터 품질 원칙](research-framework.md#데이터-품질-원칙)을 따른다.
