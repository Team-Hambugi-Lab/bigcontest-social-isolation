# 사회적 고립 연구 프레임

## 연구 질문과 해석 범위

**프로젝트 기준.** 이 프로젝트는 통신·카드 집계 데이터로 개인의 사회적 고립 여부를 판정하지 않는다. 서울 강남구와 강원 춘천시에서 사회적 고립과 연결될 가능성이 있는 지역·인구집단 수준의 이상 신호를 탐지하고, 후속 확인과 복지자원 연계의 우선순위를 제시한다.

사회적 고립은 제공 데이터에서 직접 관측되지 않는다. 따라서 문헌과 이론을 바탕으로 다음과 같은 간접 신호의 조작적 정의를 먼저 세우고, 예상되는 방향을 데이터로 검증한다.

- 대면 접촉 기회의 구조적 부족
- 활동량과 외출 패턴의 이상
- 소비 활동의 축소 또는 구조 변화
- 복지자원 접근성의 부족

관찰된 상관관계에 맞춰 사후적으로 정의를 바꾸지 않는다. 신호는 고립의 증거가 아니라 추가 확인이 필요한 후보를 찾는 근거로만 사용한다.

## 분석 단위

**프로젝트 기준.** 서로 다른 데이터 해상도를 억지로 하나의 점수로 합치지 않고 역할을 분리한다.

| 단위 | 역할 | 주요 데이터 |
| --- | --- | --- |
| 집계구 | 공간 위험 신호의 기본 단위 | SK 유동인구, SGIS 집계구 통계 |
| 행정동 | 정책 판단과 복지자원 연계 단위 | 집계구 집계 결과, 복지자원 정보 |
| 지역×성별×연령대×기준월 | 인구집단별 원인 설명과 우선지원 계층 탐색 | 신한카드 소비 집계 |

카드 데이터는 시군구보다 세밀한 공간정보가 없으므로 집계구 점수에 직접 귀속하지 않는다. 더 세밀한 공간정보가 확인되기 전까지 집계구 공간 신호와 카드 인구집단 신호를 별도 축으로 유지한다.

강남구와 춘천시는 위험군과 정상군이 아니라 도시 구조가 다른 두 파일럿 지역이다. 지역 간 절대값 비교보다 각 지역 내부 비교를 기본으로 한다.

## 공간·결합 기준

**프로젝트 기준.** 공간 분석의 기준은 다음과 같다.

- 집계구 결합키: 통계청의 14자리 `TOT_OA_CD`
- 공간조인 좌표계: `EPSG:5179`
- SK 좌표: `X_COORD`, `Y_COORD`를 `EPSG:5179`로 유지
- 다른 좌표계 자료: 좌표값을 바꾸어 적지 않고 GIS 연산으로 재투영

집계구는 공간 신호를 계산하는 단위이고 행정동은 결과를 설명하고 자원을 연결하는 단위다. 행정동 자료를 집계구에 배분해야 한다면 배분 기준과 그로 인한 불확실성을 함께 기록한다.

## 데이터 품질 원칙

**프로젝트 기준.** 원본은 수정하지 않고 `raw → interim → processed` 계보를 유지한다. 다음 상태를 구분해 기록한다.

- 원본의 결측값
- 테이블 간 `outer join`으로 생긴 커버리지 차이
- 비식별 처리를 위한 최소 건수 절단
- 실제 관측값 0

지표마다 유효 격자 수와 결측률을 함께 보존한다. 결측값이 없다는 사실만으로 집계값이 충분한 관측치를 대표한다고 판단하지 않는다.

같은 원본 테이블 안에서 분자와 분모를 구성하는 비율은 해당 테이블의 유효 관측 범위를 사용한다. 서로 다른 원본 테이블의 값을 직접 비교하거나 결합할 때는 양쪽이 모두 관측된 공통 범위로 제한해 민감도를 확인한다.

## 지표 설계

**프로젝트 기준.** 후보 지표를 계산하기 전에 다음 항목을 명시한다.

1. 지표가 나타내려는 개념
2. 위험과 연결될 것으로 예상하는 방향
3. 계산식과 분자·분모
4. 시간·공간·인구집단 단위
5. 유효 관측 범위와 결측 처리
6. 규모나 지역 구조에 의한 교란 가능성

합성지수에 넣을 후보는 값이 높을수록 위험이 커지도록 방향을 맞춘다. 다만 외부 검증에서 예상 방향이 기각되면 계산 코드를 임의로 뒤집지 않고 가설과 지표 정의를 재검토한다.

6개월 추세처럼 관측점이 적은 값은 핵심 신호보다 참고 지표로 취급한다. 반복적으로 나타나는 극단값은 측정 오류인지 확인하기 전까지 임의로 절단하지 않는다.

## 합성지수 구성 게이트

**프로젝트 기준.** 방향을 맞추고 표준화했다는 이유만으로 후보 지표를 곧바로 합산하지 않는다.

- 후보들이 같은 개념을 재는지 내적 일관성을 확인한다.
- 프로젝트의 초기 검토 기준으로 Cronbach's alpha 0.7 미만이면 기계적으로 합산하지 않는다.
- alpha는 항목 수와 지표 구조의 영향을 받으므로 단독 통과 기준으로 사용하지 않는다.
- 높은 상관을 보이는 중복 지표는 하나를 제거하거나 서로 다른 역할로 분리한다.
- 여러 합리적인 정규화·가중치 설정에서 고위험 후보가 유지되는지 확인한다.

내적 일관성이 낮으면 개별 지표를 분리해 제시하거나 사회적 고립의 조작적 정의부터 다시 검토한다.

## 검증 순서

**프로젝트 기준.** 후보 신호는 다음 순서로 검증한다.

1. 스키마, 기간, 지역 범위와 키의 유일성 확인
2. 결측, 최소 건수 절단, 양자화와 유효 표본 수 확인
3. 지표별 분포, 극단값과 변별력 확인
4. SGIS 등 독립 외부자료로 방향과 외부 타당성 확인
5. 공간 단위, 정규화, 가중치 변화에 따른 순위 민감도 확인
6. 공간 군집 결과의 이웃 거리와 통계적 유의성 확인

지표를 탐색할 때 사용한 외부변수를 동일 지표의 확정 근거로 다시 쓰는 순환 검증을 피한다. 검증을 통과하지 못한 신호는 계산 오류와 이론적 가설 기각을 구분해 기록한다.

## 결과 해석과 출력

**프로젝트 기준.** 최종 결과는 다음 역할로 나눈다.

- 집계구 위험 신호: 현장 확인이 필요한 공간 후보 탐색
- 인구집단 신호: 가능한 원인 설명과 우선지원 계층 탐색
- 행정동 결과: 복지자원 접근성과 정책 실행 단위 연결

SK와 카드 데이터는 같은 개인을 추적하지 않는다. 두 값의 동반 변화는 동일 지역·기간·연령 구간에서 나타난 공변동이며 개인 행동의 연속으로 해석하지 않는다.

6개월 자료만으로 계절성이나 고립의 진행을 입증하지 않는다. 잔차, 군집, LISA 결과 역시 사회적 고립의 확정 증거가 아니라 추가 검토 후보로 표현한다.

## 현재까지 확인한 관찰

**검증된 관찰.** 현재 프로젝트 기록에서 확인한 주요 한계는 다음과 같다.

- 강남구는 유동인구와 거주인구의 차이가 커 유동인구만으로 주민의 고립 위험을 설명하기 어렵다.
- 원본 테이블별 관측 범위가 다르면 결측이 없는 집계 결과끼리도 총량이 달라질 수 있다.
- 공간 단위와 정규화 방식에 따라 고위험 후보 순위가 달라질 수 있다.

이 관찰들은 분석 설계의 주의사항이며, 아직 최종 위험지수의 성능이나 정책 효과를 입증한 결과가 아니다.

## 미해결 항목

- **미해결:** 타깃 인구집단을 청년, 노인 또는 전 연령 중 어디에 둘지 팀 합의가 필요하다.
- **미해결:** 최종 위험지수의 구성 지표와 가중치를 확정하지 않았다.
- **미해결:** 집계구 마스터 생성과 행정동 값의 집계구 배분을 실행 검증해야 한다.
- **미해결:** 지표별 유효 격자 수와 결측률 저장을 파이프라인에 반영해야 한다.
- **미해결:** 외부 타당성 검증이 끝나지 않은 지표는 최종 지수에 포함할 수 없다.
- **제안:** 여러 합리적인 설정에서 반복해서 상위에 나타나는 후보를 우선 검토한다.
