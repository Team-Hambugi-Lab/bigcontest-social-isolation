# 사회적 고립 연구 방법론

이 디렉터리는 사회적 고립 위험 신호를 설계하고 검증할 때 반복해서 적용할 프로젝트 기준을 정리한다. 통신·카드 집계 데이터는 개인의 고립 여부를 판정하는 자료가 아니라 지역·인구집단 수준의 후속 확인 우선순위를 정하는 자료로 사용한다.

## 읽는 순서

1. [연구 프레임](research-framework.md): 분석 단위, 지표 설계, 데이터 품질과 검증 절차
2. [선행연구·조사자료](prior-research.md): 이전에 찾은 연구와 실태조사에서 가져올 수 있는 기준과 한계
3. [지원 사각지대 규모 추정](blind-spot-estimation.md): 기존 자료로 가능한 추정과 필요한 추가 관측값
4. [정책 문헌 정리](policy-literature.md): 고독·고립의 개념 구분, 단계화, 지원 연결과 평가 원칙
5. [사회적 고립 위험 지역 지표 선행연구 리뷰](social_isolation_literature_review.md): 국내외 문헌 비교, 변수 후보 및 프로토타입 실행 기록을 담은 검토 자료(2026-10-15)

데이터의 실제 구조와 결합 기준은 [제공 데이터 명세 및 활용 가이드](../data-overview.md)를 함께 참고한다.

## 문서 표기

본문의 주장은 다음 다섯 가지 상태로 구분한다.

- **프로젝트 기준**: 현재 분석과 설계에 적용하기로 한 원칙
- **검증된 관찰**: 데이터 또는 원문 자료에서 직접 확인한 내용
- **문헌 근거**: 참고문헌에서 확인했으며 프로젝트 데이터로 검증한 결과와 구분할 내용
- **제안**: 아직 구현하거나 팀 합의로 확정하지 않은 방향
- **미해결**: 추가 자료, 분석 또는 의사결정이 필요한 항목

문헌이나 정책 현황처럼 시점에 따라 달라질 수 있는 내용에는 기준일 또는 발행 시점을 표시한다.

## 적용 범위

- 분석 지역: 서울 강남구, 강원 춘천시
- 분석 대상: 개인이 아닌 비식별 지역·인구집단 집계
- 공간 신호: SK텔레콤 유동인구를 집계구·행정동 수준으로 집계
- 인구집단 신호: 지역·성별·연령대·기준월별 카드 소비 특성
- 최종 목적: 고립 확정 판정이 아닌 현장 확인과 복지자원 연계 우선순위 제시

## 관리 원칙

- 확정된 기준과 아직 검증되지 않은 가정을 같은 수준으로 서술하지 않는다.
- 외부 자료는 서지정보, 공개 원문 링크, 기준 시점을 기록한다.
- 원문 PDF는 재배포 가능 여부를 확인하기 전까지 저장소에 포함하지 않는다.
- 분석 결과로 기준이 바뀌면 관련 문서와 검증 근거를 함께 갱신한다.
