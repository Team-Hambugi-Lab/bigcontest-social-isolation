# SGIS 집계구 통계자료 코드 설명

- 출처: [koslife.tistory.com/20](https://koslife.tistory.com/20) (복층인생, 2024-05-16) — 원출처는 [통계지리정보서비스(SGIS)](https://sgis.kostat.go.kr/view/index)
- 목적: `data/raw/reference_data/집계구_통계자료/`의 CSV들이 쓰는 `METRIC_CD`(예: `to_in_001`)가 무엇을 뜻하는지 팀원이 찾아볼 수 있게 정리

## 사용하는 CSV 구조

`집계구_통계자료/` 안의 각 CSV는 헤더가 없고 열이 `[기준연도, TOT_OA_CD(14자리), METRIC_CD, 값]` 순서다. 예:

```
2024,11230510010101,to_in_001,540
2024,11230510010101,to_in_007,248
2024,11230510010101,to_in_008,292
```

아래 표에서 `METRIC_CD`를 찾아 뜻을 확인하면 된다.

## 총괄

| 코드 | 통계항목 |
| --- | --- |
| `to_in_001` | 총인구 |
| `to_in_007` | 총인구(남자) |
| `to_in_008` | 총인구(여자) |
| `to_in_002` | 평균나이 |
| `to_in_003` | 인구밀도 |
| `to_in_004` | 노령화지수 |
| `to_in_005` | 노년부양비 |
| `to_in_006` | 유년부양비 |
| `to_in_999` | 자료없는 집계구 |
| `to_ga_001` | 총가구수 |
| `to_ga_002` | 평균가구원수 |
| `to_ga_999` | 자료없는 집계구 |
| `to_ho_001` | 총주택(거처)수 |
| `to_ho_999` | 자료없는 집계구 |
| `to_fa_010` | 총사업체수 |
| `to_fa_999` | 자료없는 집계구 |

> `to_in_007`/`to_in_008`은 원 블로그 글의 표에는 빠져 있었다. 우리 저장소에 있는 SGIS 공식 코드집
> (`data/raw/국가데이터처_SGIS 행정구역 통계 및 경계/3. 코드집/2. 제공용 코드(statistics_code).xlsx`)에서
> 직접 확인해 보충했고, 실제 데이터에서도 `to_in_007 + to_in_008 = to_in_001`(예: 248+292=540)로
> 맞아떨어지는 것까지 확인했다.

## 인구 (성/연령별)

- `in_age_001`~`in_age_021`: 4세 이하부터 100세 이상까지 5세 단위 연령대별 인구
- `in_age_031`~`in_age_052`: 같은 연령대 구간의 남자 인구
- `in_age_061`~`in_age_082`: 같은 연령대 구간의 여자 인구
- `in_age_999`: 자료없는 집계구

### 교육정도별 인구

- `in_edu_001`~`in_edu_008`: 초등학교 이하 ~ 교육받지 않음
- `in_edu_999`: 자료없는 집계구

### 성/혼인상태별 인구

- `in_wed_001`~`in_wed_008`: 미혼 ~ 이혼, 남녀별
- `in_wed_999`: 자료없는 집계구

## 가구

### 점유형태별 가구

- `ga_po_001`~`ga_po_006`: 자가 ~ 무상
- `ga_po_999`: 자료없는 집계구

### 세대구성별 가구

- `ga_sd_001`~`ga_sd_006`: 1세대 ~ 비혈연가구(1인가구 포함)
- `ga_sd_999`: 자료없는 집계구

## 주택

### 연건평별 주택

- `ho_ar_001`~`ho_ar_009`: 20㎡ 이하 ~ 230㎡ 초과
- `ho_ar_999`: 자료없는 집계구

### 주택유형별 주택

- `ho_gb_001`~`ho_gb_006`: 다세대 ~ 주택 이외의 거처
- `ho_gb_999`: 자료없는 집계구

### 건축년도별 주택

분류 체계가 시기별로 다르다.

- 2000~2010년 자료: `ho_yr_001`~`ho_yr_013`, `ho_yr_999`
- 2015~2021년 자료: `ho_yr_001`~`ho_yr_017`, `ho_yr_999`

## 사업체

분류 체계가 산업분류 개정 시기별로 다르다.

- 사업체수(8차, 2000~2005년): `cp_bnu_001`~`cp_bnu_018`, `cp_bnu_999`
- 사업체수(9차, 2006~2016년): `cp_bnu_001`~`cp_bnu_019`, `cp_bnu_999`
- 사업체수(10차, 2016~2021년): `cp_bnu_001`~`cp_bnu_019`, `cp_bnu_999`
- 종사자수(8차, 2000~2005년): `cp_bem_001`~`cp_bem_018`, `cp_bem_999`
- 종사자수(9차, 2006~2016년): `cp_bem_001`~`cp_bem_019`, `cp_bem_999`
- 종사자수(10차, 2016~2021년): `cp_bem_001`~`cp_bem_019`, `cp_bem_999`

## 세부 코드가 더 필요하면

이 문서는 각 그룹의 시작·끝 코드와 뜻만 옮겨뒀다. 연령대 하나하나(`in_age_001`=몇 세인지 등) 같은
세부 항목까지 정확히 필요하면 원문 블로그의 "집계구통계코드.xls" 다운로드나, 우리 저장소의
공식 코드집(`data/raw/국가데이터처_SGIS 행정구역 통계 및 경계/3. 코드집/2. 제공용 코드(statistics_code).xlsx`,
시트 `집계구·행정동`)을 직접 열어 확인한다. 공식 코드집이 있으니 이 문서의 내용과 어긋나면
공식 코드집을 우선한다.
