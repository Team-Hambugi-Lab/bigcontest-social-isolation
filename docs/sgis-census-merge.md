# [GIS] SGIS 2024 집계구 통계 병합 — 2026-10-08

[병합 노트북](../notebooks/261008_GIS_sgis_census_merge.ipynb)은 2025년 7~12월 SK 집계구 마스터에
2024년 SGIS 통계를 집계구 코드로 연결합니다. 개인 컴퓨터 경로를 사용하지 않으며,
원본 데이터나 실행 결과는 Git에 추가하지 않습니다.

## 실행 환경

저장소 루트에서 실행하고, VS Code/Jupyter에서 프로젝트 `.venv` 커널을 선택합니다.

```bash
uv sync --extra dev
```

`pandas`와 `.xls` 읽기용 `xlrd`는 프로젝트 의존성에 선언되어 있습니다.
노트북은 저장소 루트 또는 `notebooks/`를 작업 폴더로 두고 위에서부터 실행합니다.

## 병합과 결측 처리

1. 헤더 없는 SGIS CSV 4열을 연도·집계구 코드·변수 코드·값으로 읽습니다.
2. 마스터의 기준월·집계구 중복과 SGIS의 연도·집계구·변수 중복을 검사합니다.
3. 코드표의 집계구·행정동 시트에서 변수 설명을 연결합니다. 산업 변수는 11차 설명을 선택합니다.
4. 집계구별로 변수 코드를 열로 펼치고, `TOT_OA_CD` 기준 `many_to_one` 왼쪽 결합합니다.
5. 기존 행 순서와 셀 내용이 보존되는지 병합 직후 및 저장 후 검사합니다.

결측을 임의로 0으로 바꾸지 않습니다. `numeric`은 원본 숫자(0 포함), `source_na`는 원본 `N/A`,
`no_record`는 원본에 해당 집계구·변수 행이 없다는 뜻입니다. `no_record`를 0으로 해석할지는
변수별 의미와 제공 규칙을 확인한 후 별도 분석 단계에서 결정합니다.
건축년도 코드표는 최신 구간 제목이 2023년까지라고 되어 있으나 2024년 항목까지 있어 설명표에 확인 메모를 남깁니다.

## 결과와 한계

- `master_sgis2024.csv`: 기존 마스터에 SGIS 297개 변수 추가.
- `sgis2024_variable_dictionary.csv`: 코드·한글명·출처·집계구 기준 결측률.
- `sgis2024_value_status.csv`: 집계구당 한 행의 값 상태표.
- `merge_report.json`: 상대 입력 경로, 코드 매칭, 중복 검사 후 행 수, 저장 검증 기록.

제공 자료 검증 결과는 집계구 1,698개, 마스터 10,188행 × 194열, 병합 결과 10,188행 × 491열입니다.
2024년 SGIS는 월별 변화량이 아닌 고정된 지역 특성으로 반복됩니다. 여러 달을 합칠 때 SGIS 값을 중복 합산하면 안 됩니다.
집계구 코드 일치가 공간 경계 동일성을 뜻하지는 않으며, 이 노트북은 경계 동일성을 검증하지 않습니다.
