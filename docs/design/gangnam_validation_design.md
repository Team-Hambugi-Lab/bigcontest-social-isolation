> 작성일: 2026-10-23
>

## 1. 목적과 경계

통신 관심집단 검증의 [설계](telecom_validation_design.md)와 [보고서](../../reports/261022_EDA_telecom_validation_v3.md)가 강남 22개 동의 **SGIS v3.3 지수 ↔ 외출·커뮤니케이션이 모두 적은 집단의 추정 비율** 비교를 담당한다. 같은 주 지표와 v3.3 순위 상관을 다시 계산하지 않는다. 이 보완 검증은 1차 프로토타입에서 **노후주택 차원을 빼면 동별 결과가 달라지는지**, **빠진 집계구가 어디에 몰렸는지**, **다른 통신 신호가 같은 방향인지** 확인한다.

이는 행정동 집계값 사이의 **연관성 검토**다. 통신 관심집단은 모형 추정값이며 실제 고립 여부의 정답이 아니다. 지역 결과로 개인 위험 등급을 정하지 않는다. 1차 프로토타입에는 SK 유동 차원이 들어 있고 통신 관심집단 검증의 v3.3에는 없으므로 두 지수의 점수·등급을 같은 척도로 직접 비교하지 않는다.

## 3. 비교 기준

### 3.1 노후주택 포함·제외

두 CSV를 `TOT_OA_CD`로 일대일 연결하고, 코드·`ADM_CD` 집합과 가구 수가 같은지 먼저 확인한다. **동 점수는 평가된 집계구의 일반가구 수(`SGIS2024_to_ga_001`) 가중평균**으로 만든다. 두 버전의 평가 집합과 가중치는 동일하게 고정한다. 집계구 `grade`는 전체 1,649개 기준 5등급이므로 동 등급처럼 평균하지 않는다. 대신 동별 5등급 집계구 수·가구 비중과 동 점수 순위를 나란히 놓는다.

22개 동에서 각 버전의 동 점수와 통신 관심집단 검증 `ratio_pop_all`의 Spearman 순위 상관을 같은 22개 동에 대해 계산한다. 65세 이상 `ratio_pop_old65`도 별도 대조한다. 차이 자체는 두 상관계수와 동 순위 변화로 제시하고, 22개 동 복원추출을 같은 표본으로 적용한 상관 차이의 95% 구간과 leave-one-out 범위를 함께 본다(`random_state=42`, 2,000회). 어느 버전이 우월하다고 단정할 기준으로 쓰지 않는다. 사전 선택한 은마·현대아파트 관련 동은 이름과 해당 집계구를 자료로 확인한 뒤 사례로 설명한다. 아파트 명칭만으로 집계구 위치를 추정하지 않는다.

### 3.2 빠진 49개 집계구와 동별 평가 범위

마스터에서 2025년 7월 한 행씩 골라 전체 1,698개 코드를 고정한다. 같은 집계구의 SGIS 값이 다른 달에 달라지지 않았는지 확인한다. 프로토타입에 없는 코드를 `left` 조인으로 남기고, 노트북·[프로토타입 노트북](../../notebooks/261015_GIS_isolation_index_prototype.ipynb)의 원래 포함 조건인 `총인구 > 0`, `일반가구 > 0`, `총주택 > 0`, 첫 달 `HAS_SK_POINTS`를 각각 검사한다. 조건이 여러 개 실패한 경우 플래그를 모두 보존하고, 설명용 대표 사유는 인구 없음 → 가구 없음 → 주택 없음 → SK 없음 순으로 붙인다. 이 순서는 사유별 집계를 중복 없이 보여 주기 위한 표시 규칙이지 새 지수 제외 기준이 아니다.

동별로 전체·평가·제외 집계구 수와 **전체 일반가구 중 평가된 일반가구 비중**을 낸다. 가구 수가 0인 동은 비중을 결측으로 둔다. 전체 1,698개와 빠진 49개의 코드가 정확히 복원되고, 동별 개수 합이 전체와 같아야 한다. 인구가 있는 제외 집계구의 인구·가구 규모를 따로 보여 자료 누락이 동 순위 해석에 주는 한계를 적는다. 원 지수의 49개를 임의 점수로 채우지 않는다.

### 3.3 보조 통신 신호

`src.data.paths.interest_group_files`, 통신 관심집단 검증의 동 코드 변환·대응표와 6개월 처리 규칙을 재사용한다. 관심집단 보조 열 두 개는 통신 관심집단 검증와 같은 **동·성·5세 연령·월 인구**를 분모로 한다. 먼저 동×대상집단×월마다 분자와 분모를 각각 합산해 비율을 만들고, 6개월 평균을 한 번 낸다. 주 결과와 달리 이 두 집단은 구성 기준이 겹칠 수 있으므로 독립 검증 2건으로 세지 않는다.

29개 통신정보에서는 `평균 통화대상자 수`, 평일·휴일 집 체류시간, 평일·휴일 이동 횟수를 확인한다. 활동 신호 외부검증의 `src/evaluation/h4_external_validation.py`에 있는 체류·이동 열 이름과 동 코드 변환을 재사용한다. 셀 단위 값은 같은 동·대상 연령의 유효 인구로 가중해 월별 평균을 구하고 6개월 평균한다. 지표에 대응하는 `미추정 인구수` 열이 있으면 `총인구수 − 미추정 인구수`를 가중치로 쓰고, 없으면 총인구수를 쓴다. 값이 결측인 셀은 분자·가중 분모에서 함께 빼며, 가중치가 0이면 동 지표를 결측으로 둔다. 동별 유효 셀·인구 비중과 지표별 가중치 정의를 남긴다. 미추정 인구수를 실제 0값으로 채우지 않는다. 통화대상자·이동 횟수가 적고 집 체류시간이 길수록 위험 방향이라는 해석은 **사전 가설**로 두되, 관심집단 구성에 이동·통화가 포함돼 있어 이 비교를 독립적인 외부 검증으로 주장하지 않는다.

연령은 전체, 통신 관심집단 검증의 65세 이상, 원안의 60세 이상(`60, 65, 70, 75` 시작 구간)을 구분한다. 60세 이상에는 60~64세가 추가되므로 결과를 65세 이상과 동일하게 부르지 않는다. 대상 집단과 동 코드가 22개로 정확히 연결되지 않으면 상관을 계산하지 않고 원인을 먼저 확인한다.

## 4. 구현·산출 순서

1. 입력 해시·열·키 중복·22개 동 매칭을 점검한다. 통신 관심집단 검증 결과 파일은 읽기만 한다.
2. `src/features/seoul_comm.py`에는 통신 관심집단 검증가 제공하지 않는 보조 관심집단·29개 통신정보 집계와 프로토타입 동 집계만 추가한다. 기존 통신 관심집단 검증 함수가 맞는 곳은 그대로 호출한다.
3. 작은 합성 표로 **분자 합 ÷ 분모 합**, 유효 셀만 가중하는 평균, 49개 사유 플래그의 중복·우선순위를 확인하는 테스트를 작성한다. 로컬 원자료가 있어야 하는 검사는 `requires_data`로 표시한다.
4. `data/processed/seoul_comm_gangnam_dong.csv`, `validation_gangnam_dong.csv`와 각 열 정의서를 로컬에 만든다. 통신 관심집단 검증의 22개 동 주 지표를 출처 열과 함께 연결하고, 프로토타입 두 버전·평가 범위·보조 지표를 담는다. CSV는 UTF-8, 코드 열은 문자열이다.
5. `reports/261023_REG_gangnam_dong_validation.md`에 동별 대조표, 두 버전 산점도, 상관과 민감도, 제외 49개 영향, 60세 이상·65세 이상 차이, 자료 한계를 기록한다. 통신 관심집단 검증 보고서의 수치를 재현한 새 분석으로 표기하지 않는다.
6. `uv run ruff check src/ tests/`, `uv run ruff format --check src/ tests/`, `uv run --extra dev --extra gis pytest tests/ -v`를 실행하고 결과를 보고한다. 전체 테스트에는 이미 선언된 GIS 선택 의존성이 필요하다.

## 5. 해석 한계와 완료 판단

- 통신 관심집단 검증의 v3.3 행정동 점수는 유효 일반가구 가중평균이고, 1차 프로토타입은 다른 차원·결측 처리·전체 백분위 등급을 쓴다. 두 결과의 절대 점수나 등급을 서로 빼지 않는다.
- 1차 프로토타입의 SGIS는 2024년, 유동·서울 통신 자료는 2025년 7~12월이다. 6개월 통신 월값은 직전 3개월 평균이 겹치므로 독립 표본 6개로 취급하지 않는다.
- 프로토타입의 0 대치와 주거취약 차원 중복 가능성, 49개 제외 집계구, 강남 22개 동이라는 표본 범위를 보고서에 남긴다.
- 결과가 가설과 반대로 나와도 지수 계산 오류로 단정하지 않는다. 계산 재현성, 분모·coverage, 위험 방향 가정을 따로 확인한다.
- 완료는 두 프로토타입의 같은 동·같은 평가 집합 비교, 49개 코드 전수 설명, 보조 지표의 유효 관측 범위, 보고서·열 정의서·관련 검사 결과가 모두 갖춰졌을 때로 판단한다.
