# 고립 위험 특징 사전 근거

에이전트의 특징 코드 부여, 기관 추천 태그 매칭, 지역 지수 차원이 같은 어휘를 쓰도록 만든 위험 특징 사전의 근거를 정리한다. 사전은 점수를 내는 지수가 아니라 **가중치 없는 분류표**다. 특징마다 해당 여부만 판정한다.

- 최종 사전: `data/processed/risk_feature_dictionary.csv` (청년·고령 병합 후)
- 생성 코드: `uv run python -m src.features.risk_features_youth`(청년 근거), `uv run python -m src.features.risk_feature_dictionary`(병합)

## 공통 정의

**범주 7개**

| 코드 | 이름 | 한 줄 정의 |
|------|------|-----------|
| `REL` | 관계 단절 | 어려울 때 의지하거나 속마음을 나눌 사람이 없고, 가족·주변과의 관계가 끊겼거나 갈등이 크다 |
| `OUT` | 외출·활동 부족 | 사회활동(일, 학업, 모임)에 참여하지 않고 집 안에서 보내는 시간이 길다 |
| `SOLO` | 독거 | 혼자 살아서 일상에서 마주하는 사람이 없다 |
| `BODY` | 신체건강·일상생활 | 신체 건강이 나쁘거나 장애가 있고, 식사·위생·수면 같은 일상 관리가 어렵다 |
| `MIND` | 정신건강 | 우울·불안·절망 등 정서 어려움이 있거나 정신과 진단·투약 중이다 |
| `ECON` | 경제적 어려움 | 소득 활동이 없거나 불안정하고 스스로 경제 수준을 낮게 본다 |
| `HOUSE` | 주거 취약 | 고시원 등 준주거시설이나 월세·무상 거주처럼 주거가 불안정하다 |

- 사전의 행은 범주 아래의 특징이다(예: `MIND_SUICIDE_IDEA`).
- 같은 특징이 연령별로 다르면 범주를 나누지 않고 `AGE_PATTERN`에 적는다.
- `BODY`는 `HEALTH`와 `LIFE`로 나누지 않고 하나의 범주로 유지한다(아래 "BODY 범주 판단").

**특징 정의는 "지금 감지하는 상태" 기준이다.** 사전은 설문 응답자를 분류하는 표가 아니라, 에이전트가 사용자에게서 지금 감지한 특징을 분류하는 표다. 설문 비율은 그 특징이 왜 중요한지 보여 주는 근거일 뿐이다. 정의와 근거를 섞으면 결정이 흔들린다(아래 `IS_CRISIS` 참고).

**`IS_CRISIS` 기준:** 생명이나 안전에 즉각 위험이 되는 특징만 위기로 본다. 판단이 애매하면 위기 쪽으로 둔다.
- 위기 특징은 `MIND_SUICIDE_IDEA`(지난 2주 안의 자살·자해 생각)와 `MIND_SUICIDE_ATTEMPT`(지난 2주 안의 자살 시도·자해 행동) 둘이다.
- 보건복지부 `q14`("죽고 싶다고 생각한 적이 있나요")는 평생 경험이라 은둔 74.9%, 고립 75.0%가 해당한다. 이 문항을 그대로 위기 기준으로 쓰면 고립·은둔 청년 4명 중 3명이 위기가 된다. 그래서 정의에 시점(지난 2주)을 넣고, 시점이 맞는 근거로 서울시 `B12_9`(PHQ-9 9번, 지난 2주)를 쓴다. "거의 매일"이 고립·은둔 18.3%, 전체 청년 4.4%다.
- 외부 근거: 보건복지부 고독사위기대응시스템(2026-02-27 개통)의 위기정보 27종에 자살고위험관리대상자와 내원사유 자해/자살 대상자가 포함된다. 27종은 고독사 위험군을 찾는 선별용 목록이라 전부 즉시 이관 기준은 아니다.

특징별 메모
- `BODY_HYGIENE`의 세수·양치(`q83`)는 서울시에서 전체 청년이 더 높게 나왔다(반대 방향). 보건복지부에서는 은둔(5.6%)이 고립(3.5%)보다 높고, 서울시 전체 청년 분포가 어색해(일주일에 한 번 6.9%, 2-3일에 한 번 7.4%) 응답 품질 문제일 가능성이 있어 포함했다.

- 집단 안에서 70% 이상이 해당하는 특징(`ECON_LOW_STATUS`, `MIND_HOPELESS`, `MIND_SOCIAL_ANXIETY`)은 기준이 느슨할 수 있다. 보건복지부 조사만으로는 판단할 수 없어 기준을 유지했다.

## 감지 데이터 (`DETECT_DATA`, `DETECT_RULE`)

`DETECT_DATA`는 SGIS / SK / 신한카드 / 감지 불가 중 하나이고, `DETECT_RULE`은 그 데이터로 감지하는 방법이다. 지역·집단 단위 신호라서 개인 티어를 올리지 않고 관찰 빈도만 높인다.

| 감지 데이터 | 특징 | 방법 | 미정 사항 |
|------|------|------|------|
| SGIS | `SOLO_LIVING`, `HOUSE_UNSTABLE` | 지수 v3.2: `SOLO_LIVING`은 테마 A `solo50`(1인가구율×50세+ 비율)·테마 B `male_solo`, `HOUSE_UNSTABLE`은 테마 B `housv`(비주거용 건물 내 주택·20㎡ 이하)·`other50`(주택 이외 거처×50세+, 고시원 대리) | 50세 이상 가중이라 청년은 지역 신호로 잡히지 않고 대화로 확인한다(10/22, v3.2 반영) |

| 신한카드 | `ECON_NO_INCOME`, `ECON_LOW_STATUS` | 거주지 20·30대 집단의 소비가 낮거나 줄어듦 | 강남구·춘천만 해당 |
| 감지 불가 | 나머지 16개 | 지역 데이터로 감지할 수 없고 대화(체크인)로 확인 | `OUT_LONG_DURATION`은 같은 이유로 SK에서 옮김(10/22) |

## 필요 지원 (`SUPPORT_TYPES`, `SUPPORT_NEED_PCT`)

보건복지부 필요 지원 문항(`q211`-`q2110`, 4점 척도)의 "매우 필요함" 비율을 쓴다.

- "매우 필요함" 비율 순으로 고르면 21개 특징 모두 경제적 지원이 1위라 특징 간 구별이 없다. 경제적 지원은 고립·은둔 청년 전반의 기본 지원으로 보인다(은둔 60.5%, 고립 56.7%).
- 그래서 **특징 해당자의 비율이 전체 응답자(은둔+고립 합산)보다 높은 차이 순**으로 상위 3개를 고르고, `SUPPORT_NEED_PCT`에는 해당자의 실제 비율을 적는다.
- 결과 예: 정신건강·자살 관련 특징은 전문가 상담·치료, `ECON_NO_INCOME`은 취업·일 경험과 교육·학습, `SOLO_LIVING`은 혼자·같이 하는 취미 활동, `REL_LONELY`와 `MIND_SOCIAL_ANXIETY`는 머물 수 있는 공간이 상위다.
- 도움받지 않은 이유(`q20a1`)는 특징이 아니라 추천 문구 근거로 `risk_features_youth.csv`에 분포만 둔다(원하지 않아서 은둔 38.4%·고립 39.4%, 요청할 곳 몰라서 27.9%·28.3%).

### BODY 범주 판단

**하나의 범주로 유지한다.**

- 건강 상태: 주관적 건강, 질환, 장애와 생활 제약은 `BODY_POOR_HEALTH`에서 다루되 서로 다른 측정값임을 기록한다. S4 p.39~40(PDF3~4)은 주관적 건강과 만성질환을 별도 측정한다.
- 위생: `BODY_HYGIENE`에 세수·양치·목욕 등 ADL 수행을 연결한다.
- 생활공간 관리: `BODY_HOME_CARE`에 집안일·청소·세탁 등 IADL 수행을 연결한다.
- 이동·외출 수행 곤란은 `BODY_MOBILITY_LIMIT`를 후보로 제안한다. 활동에 참여하지 않는 OUT과, 수행능력에 제한이 있는 BODY를 구분할 수 있다.

S3 p.6(PDF6)의 기능 제한 **18.6%는 ADL 또는 IADL의 합친 값**이다. 위생 곤란 또는 청소 곤란의 비율로 복제하면 안 된다. 청년과 고령의 원인 차이는 AGE_PATTERN에 기록하면 된다. 따라서 HEALTH/LIFE로 상위 범주를 분리해야 할 직접적인 이유는 이번 검토에서 확인되지 않았다.

결론: 기본계획은 사회적 고립·생활지원 필요 위험군을 찾는 정책 근거로 쓸 수 있지만, 프로젝트의 즉시 사람 이관 기준 전체를 직접 검증하지는 않는다. ‘위기 가구’라는 표현의 출현 여부와 무관하게 **최근 2주 생각·행동을 기준으로 하는 운영 정의는 찾지 못했다.**

#### IS_CRISIS 처리

- 프로젝트 정의에 맞춰 `MIND_SUICIDE_IDEA`, `MIND_SUICIDE_ATTEMPT` 두 특징의 IS_CRISIS를 1로 두었다. 이는 **특징의 사람 이관 표시**이고, 특정 개인이 현재 즉각적 위험 상태라는 임상 판정값이 아니다.
- S4 p.41(PDF5)의 고령층 자살 생각 **1.0%는 지난 1년** 경험이다. 지난 2주 비율, 자해 생각까지 포함한 비율, 현재 위기 비율로 사용할 수 없다. 최근 시도·자해 행동의 동일 기간 고령 수치는 본 자료에서 확인하지 못했다.
- S6 NIMH 성인 후속평가 지침은 최근 생각의 빈도·마지막 시점, 현재 생각, 계획, 과거 행동 이력을 각각 확인한다. 따라서 프로젝트의 2주 구분만으로 자동 응급도를 결정하거나, 2주 이전 시도 이력을 버리는 근거로 쓰지 않는다. 해당 평가는 훈련된 전문가의 역할이며 한국 서비스의 검증된 자동 규칙으로 제시하지 않는다.

### 고령 수치를 채우지 않은 특징

REL_NO_ADVICE, REL_FAMILY_CONFLICT, REL_NO_FAMILY, REL_LONELY, OUT_LONG_DURATION, SOLO_MEAL, BODY_SLEEP, MIND_HOPELESS, MIND_SOCIAL_ANXIETY의 **정확히 대응하는 고령 수치·문항**은 이번 범위에서 확보하지 못해 본표에 억지로 채우지 않았다. 고령층에 특징이 없다는 뜻은 아니다. 특히 하루 식사 1회는 혼자 식사 여부가 아니며, 연락 가능한 자녀 없음은 가족 전체가 없다는 뜻이 아니다.

## 병합 사전 (`data/processed/risk_feature_dictionary.csv`)

생성 코드: `uv run python -m src.features.risk_feature_dictionary`.

- **행:** 10/20에 확정한 21개 코드와 10/22에 채택한 고령·중장년 제안 코드 3개, 모두 24행이다. 고령 12개는 모두 21개 코드 안에 있다. 연령별로 다른 점은 범주를 나누지 않고 `AGE_PATTERN`에 적는다.
- **청년 값을 쓰는 열:** `FEATURE_NAME`, `DEFINITION`, `DETECT_DATA`, `IS_CRISIS`, `SUPPORT_TYPES`, `SUPPORT_NEED_PCT`. 정의는 10/20 확정본이고, `SUPPORT_NEED_PCT`는 실태조사 "매우 필요함" 비율이라 같은 문항이 없는 고령 지원 제안은 넣지 않는다.
- **연령대별로 잇는 열:** `AGE_PATTERN`, `EVIDENCE_SOURCE`, `EVIDENCE_VALUE`, `DETECT_RULE`. `[청년] … [고령·중장년] …` 형식이고, 고령 근거가 없는 9개는 `AGE_PATTERN`에 "근거 자료 없음"으로 적는다.
- **기관 후보 열:** `INSTITUTION_TAGS`는 [기관 서비스 태그 매핑](resource-tags.md)의 44행에서 특징별 `PRIORITY` 순으로 채운다. 후보 태그만으로 기관 이용 자격이나 추천을 확정하지 않는다.
- **고령·중장년 제안 코드 3개(10/22 채택):** `REL_NO_PRACTICAL_SUPPORT`(아플 때 도와줄 사람 없음), `REL_LOW_CONTACT`(사회적 교류 드묾), `BODY_MOBILITY_LIMIT`(이동·외출 수행 어려움). 사전은 지금 감지하는 특징의 표라 청년 근거가 없어도 코드를 둔다. 이름·정의·감지 방법은 고령·중장년 작업본을 따르고, 같은 범주의 마지막 행 뒤에 넣는다.
  - 청년 근거는 `REL_LOW_CONTACT`에만 있다. 서울시 `A11`(2주 교류 0회, 고립·은둔 26.8% 대 전체 청년 3.4%)은 교류 빈도 문항이라 `REL_NO_CONFIDANT`에서 이 코드로 옮겼다. 나머지 둘은 "청년 실태조사 근거 없음"으로 적는다.
  - 보건복지부 문항이 없어 세 코드의 `SUPPORT_TYPES`·`SUPPORT_NEED_PCT`는 비어 있다.
- **`BODY` 유지(10/22 확정):** 고령·중장년 검토대로 `HEALTH`·`LIFE`로 나누지 않는다.
- `IS_CRISIS`는 두 작업본이 같다(위기 2개). 다르면 코드가 멈춘다.
