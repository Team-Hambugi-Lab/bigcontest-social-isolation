# 고립 위험 특징 사전 A-1(청년 쪽) 설계 문서 (#17)

> 작성일: 2026-10-18 / 담당: A-1 정연 / 마일스톤 M2 (10/21 분석 동결)

**Goal:** 보건복지부 고립·은둔 청년 실태조사(2023)와 서울시 고립은둔청년 실태조사에서 위험 특징 근거를 집계해 `risk_features_youth.csv`와 열 정의서를 만든다. A-2(고령·중장년) 표와 병합할 때 쓰는 청년 쪽 입력이다.

**Architecture:** 새 모듈 `src/features/mohw_survey.py` 하나에 순수 함수로 나눠 담는다. 코드북 읽기, 결측 정리, 문항별 분포 집계 순서이고, `main()`으로 실행한다(`uv run python -m src.features.mohw_survey`). 원본 xlsx는 읽기만 한다.

**Tech Stack:** Python 3.11+, pandas, openpyxl, pytest(`requires_data` 마커), uv, ruff. 새 의존성은 없다(openpyxl은 확인 후 `pyproject.toml`에 없으면 `uv add`).

**Spec:** 별도 spec 문서는 없다. 이슈 #17 본문을 spec으로 삼는다.
- 위험 요인 계수가 아니라 특징 프로필과 필요 지원으로 정리한다(비교군이 없다).
- 가중치를 쓰지 않는다. 해당 여부와 비율만 낸다.
- 개인 응답 원자료는 산출물에 넣지 않는다. 비율·집계값만 넣는다.

### 집계 표 형식 (긴 형태, 92행)

필요 지원(`SUPPORT_NEED`, 10문항 × 4보기 × 2집단 = 80행)과 도움받지 않은 이유(`HELP_BARRIER`, `q20a1` 6보기 × 2집단 = 12행)를 한 파일에 세로로 합친다. 열이 서로 다른 두 표를 가로로 맞추지 않으려고 문항×보기 단위 긴 형태로 통일했다.

| 열 | 설명 |
|----|------|
| `TABLE` | `SUPPORT_NEED` / `HELP_BARRIER` |
| `GROUP` | 은둔 / 고립 |
| `ITEM_CODE`, `ITEM_LABEL` | `q211` / "눈치 보지 않고 들러서 머물 수 있는 공간" (코드북 문구에서 접두 제거) |
| `OPTION_CODE`, `OPTION_LABEL` | 보기 코드와 문구 |
| `N` | 그 보기를 고른 응답 수 (응답이 없는 보기도 0으로 남김) |
| `N_VALID` | `'.'`을 뺀 문항별 유효 응답 수. 비율의 분모 |
| `PCT` | `N / N_VALID`, 소수점 1자리 % |

사전의 `SUPPORT_NEED_PCT`는 `TABLE = SUPPORT_NEED`이고 `OPTION_CODE = 4`("매우 필요함")인 행의 `PCT`다. 사전 병합(Task 3 이후)에서 가로로 펼친다. `HELP_BARRIER`의 분모는 `q20a1` 응답자(은둔 2,925명, 고립 2,017명)다.

## 주의 (해석 범위)

- 이 조사는 고립·은둔 청년에게만 물었다. 비율은 "고립·은둔 청년 중 몇 %가 이 지원을 매우 필요로 하는가"이고, 일반 청년의 위험 요인 계수가 아니다.
- 가중치가 없으므로 모집단 추정값이 아니라 표본 비율이다. 보고서 문구에 "표본 기준"을 명시한다.
- 서울시 조사의 정의(고립지수)와 보건복지부의 판정 기준은 다를 수 있다. 같은 표에 합칠 때 `EVIDENCE_SOURCE`로 구분하고, 판정 기준 원문은 김성아 외(2023) 부록에서 확인한다.
