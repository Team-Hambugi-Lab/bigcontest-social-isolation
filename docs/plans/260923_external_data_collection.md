- 기상: 지역별 184행, 날짜 중복·결측·온도 범위 위반·음수 강수/적설 없음

- 전철: 6개 월 모든 날짜 존재, 결측·음수·`사용일자 × 노선명 × 역명` 중복 없음
- 시설: HWPX 구조 정상, 강남구·춘천시 시설 정보와 2024년 말 기준 시점 확인

## 자료별 한계

- 기상 주 입력은 Open-Meteo ERA5 격자 추정치다. 서울 관측소 좌표는 종로구에 있어 강남구의 도시권 대리변수로만 사용한다.
- 강남구 전철 자료에는 공개 원본 안내상 신분당선이 포함되지 않는다. 춘천 자료는 경춘선 6개 역이며 관광·통근·통학 수요가 혼합돼 있다.
- 행사 자료는 공식 게시물에서 선별한 목록으로 소규모 행사와 비공개 행사를 망라하지 않는다. 행사 수를 방문객 수로 해석하지 않는다.
- 노인복지시설은 2024년 말 기준이다. 2025년 하반기 실제 운영 여부와 시설별 서비스 가용성은 추가 확인이 필요하다.
- 춘천시의 2025년 동기간 버스 승하차 원본과 인증 없는 월별 관광객 원본은 확보하지 못했다.

## 별도 이슈 범위: 외부 요인 검증 분석

### 1. 일별 카드 소비와 외부 요인 결합

다음 단위로 신한카드 주제2 데이터를 집계한다.

```text
일자 × 지역 × 성별 × 연령대
```

`일자 × 지역`을 결합 키로 기상·공휴일·행사 데이터를 추가한다.

- 평균·최저·최고기온
- 강수량과 적설량
- 요일·주말·공휴일 여부
- 지역 행사 활성 여부와 활성 행사 수

결합 후 행 수가 변하지 않는지, 외부 변수 결측이 없는지, 키 중복이 없는지 검증한다. 기상·공휴일·행사별 결제건수와 결제금액 분포를 먼저 비교하고, 해석 가능한 기준 모델로 외부 요인을 반영한 예상 결제건수를 산출한다.

```text
잔여 소비 = 실제 결제건수 - 외부 요인 반영 예상 결제건수
```

잔여 소비는 인과효과나 고립 여부가 아니다. 외부 요인으로 설명되지 않은 변동을 찾는 탐색 지표로만 사용한다.

### 2. 전철 승하차로 지역 이동량 교차검증

전철 원본을 강남구 26개 역과 춘천시 경춘선 6개 역으로 필터링한 뒤 다음 단위로 집계한다.

```text
기준월 × 지역
```

- 월별 승차·하차·총승하차 인원
- 7월 기준 지수와 전월 대비 증감률
- SK 전체 유동인구 변화와 전철 승하차 변화 방향 비교
- 신한카드 지역 전체 결제건수 변화와 비교

지역별 역 수와 교통 공급이 다르므로 강남구와 춘천시의 절대량을 직접 비교하지 않는다. 관측점이 6개월뿐이므로 상관계수나 유의확률을 핵심 근거로 사용하지 않고 변화 방향과 크기를 보조 근거로 제시한다. 전철 자료에는 성별·연령대가 없으므로 지역 전체 이동량만 검증한다.

### 3. 주요 행사 구간 해석

행사 활성일과 비활성일의 지역별 카드 결제·전철 승하차 차이를 확인한다. 특히 다음 기간을 별도로 표시한다.

- 춘천 7월: 태권도 국제행사와 썸머워터페스티벌
- 춘천 10월: 커피·재즈·탱고 축제
- 강남 9~10월: 강남페스티벌
- 강남 10~12월: 코엑스 대형 전시·박람회

행사일의 단순 차이를 행사 인과효과로 해석하지 않는다. 요일·공휴일·날씨가 겹치는지 함께 확인하고, 공식 목록에 포함되지 않은 행사가 있을 수 있음을 명시한다.

### 4. 외부 요인 반영 전후 후보 재평가

기존 `기준월 × 지역 × 성별 × 연령대` 고립 의심 신호와 외부 요인을 반영한 결과를 비교한다.

| 비교 항목 | 확인 내용 |
| --- | --- |
| 유동인구 | 감소 규모와 지속 기간 |
| 카드 소비 | 원자료 증감과 잔여 소비 증감 |
| 소비권역 | 외지 결제 비중과 거주 시도 다양성 변화 |
| 교통량 | 지역 전체 전철 승하차 변화 방향 |
| 외부 요인 | 날씨·공휴일·행사로 설명되는 정도 |

외부 요인을 반영한 뒤에도 이동·소비 감소가 지속되는 집단을 우선 검토 후보로 남긴다. 후보 순위는 위험 확률이 아니라 추가 확인 우선순위로 정의한다.

## 별도 후속 범위: 복지자원 추천 데이터 준비

노인복지시설 HWPX에서 강남구·춘천시 시설을 추출해 시설명, 유형, 주소, 연락처, 정원·현원과 제공 서비스를 정리한다.

1차 지표는 지역별 시설 수와 고령인구 대비 시설 수로 제한한다. 좌표를 확보하거나 주소를 지오코딩한 뒤에만 행정동별 거리·접근성 지표를 추가한다. 2024년 말 자료이므로 실제 추천 전 운영 여부를 확인해야 한다.

에이전트에서는 다음 흐름의 기초 자료로 사용한다.

```text
고립 의심 신호 탐지
→ 외부 요인과 위험 원인 후보 설명
→ 위험 수준에 맞는 시설 유형 선택
→ 지역 내 복지시설 후보 제시
```
