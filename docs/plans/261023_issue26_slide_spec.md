## 1. 표현 원칙

- **헤드라인은 발견이나 결정을 단정문 한 줄로 쓴다.** 핵심어 하나만 강조색을 넣는다.
- **한정 표현은 슬라이드 하단 각주 한 줄로 둔다.** 대리지표, 강남 22개 동, 추정 같은 표현이다. 신뢰구간·판별 조건·모델 정의는 질의응답 준비(10절)로 보낸다. 부록은 두지 않는다.
- **한계는 "문제 → 결정"으로 쓴다.** 예: "20대 신호는 방향이 반대였다 → 고령에 집중했다", "판단할 수 없는 곳 → 지우지 않고 따로 관리한다".
- **헤드라인이 사실을 넘지 않는다.** 아래 금지 표현은 쓰지 않는다.

| 쓰지 않는 표현 | 이유 | 대신 |
|---|---|---|
| "혼자 사는 고령자 수를 셌다" | 연령 × 가구형태 교차표가 없다. `solo50`은 1인가구율 × 50세+ 비율 | "대리지표" 각주 |
| "고립 확률", "강남이 춘천보다 위험" | 등급은 지역 안 상대 순위 | "지역 내 상대 등급" 각주 |
| "탐지 정확도 97%" | R² 0.971은 학습 자료의 로그 유동 적합도 | "기대 유동 모델 적합도" |
| "8번 검증 모두 통과" | 행동 지표 4개 × H4 요약값 2개 대조. 독립 실험 8번이 아님 | "8개 대조 모두 예상 방향" |
| "v3.3이 더 정확하다" | #15의 0.421 → 0.606 차이 구간이 0을 포함 | "버전마다 같은 기준으로 재검증" |
| "복지 사각지대 96곳" | 30곳은 원자료 인구 0. 보류 사유가 다양 | "판단 보류" |
| "157곳은 고령 독거 고위험 지역" | watch에 중장년 테마 포함. B만 상위인 곳 66곳 | "두 축이 겹치는 곳" |
| "노후주택을 비아파트로 한정했다" | `oldho` = 노후주택 비율 × 비아파트 비율. 교차 집계가 아님 | "비아파트 비율을 곱한 대리지표" |
| 효과 수치("발굴률 ○% 향상" 등) | 시뮬레이션·효과 검증을 하지 않았다 | 에이전트 동작 설계로 제시 |

## 2. 목차 (5장, 약 15분)

참고 자료(세종시 C.P.A)의 4단계 목차에 에이전트 장을 더했다. 왼쪽 위에 `01 왜 필요한가`처럼 위치를 작게 표시한다.

| 장 | 제목 | 슬라이드 | 시간 |
|---|---|---|---:|
| 01 | 왜 필요한가 | 1~3 | 2.5분 |
| 02 | 어떻게 찾았나 | 4~11 | 6분 |
| 03 | 무엇을 찾았나 | 12~13 | 2분 |
| 04 | 어떻게 곁에 있을까 (에이전트) | 14~17 | 3.5분 |
| 05 | 무엇이 달라지나 | 18~20 | 1분 |

- 같은 슬라이드를 반복하며 강조 위치만 옮기는 연출(12번 유형 카드 체크, 7·9번 축 강조)은 장 수에 넣지 않는다.
- 주조색은 남색 하나로 하고, 유형별 색(12번)을 정해 03~04장 끝까지 유지한다.
