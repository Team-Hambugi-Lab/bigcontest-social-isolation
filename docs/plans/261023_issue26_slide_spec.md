## 1. 표현 원칙

- **제목은 두 줄 체계로 쓴다(10/24, 고립·은둔청년 최우수상 형식).** 위 줄은 `단계 | 세부` 명사형 라벨(예: `축 1 노출 지수 | 지수 산출`), 아래 줄은 발견이나 결정을 담은 단정문 한 줄. 핵심어 하나만 강조색. 라벨 목록은 "Canva 제목 정리" 절.
- **한정 표현은 슬라이드 하단 각주 한 줄로 둔다.** 대리지표, 강남 22개 동, 추정 같은 표현이다. 신뢰구간·판별 조건·모델 정의는 질의응답 준비(9절)로 보낸다. 부록은 두지 않는다.
- **한계는 "문제 → 결정"으로 쓴다.** 예: "20대 신호는 방향이 반대였다 → 고령에 집중했다", "판단할 수 없는 곳 → 지우지 않고 따로 관리한다".
- **헤드라인이 사실을 넘지 않는다.** 아래 금지 표현은 쓰지 않는다.

| 쓰지 않는 표현 | 이유 | 대신 |
|---|---|---|
| "혼자 사는 고령자 수를 셌다" | 연령 × 가구형태 교차표가 없다. `solo50`은 1인가구율 × 50세+ 비율 | "대리지표" 각주 |
| "고립 확률", "강남이 춘천보다 위험" | 등급은 지역 안 상대 순위 | "지역 내 상대 등급" 각주 |
| "탐지 정확도 97%" | R² 0.971은 학습 자료의 로그 유동 적합도 | "기대 유동 모델 적합도" |
| "8번 검증 모두 통과" | 행동 지표 4개 × H4 요약값 2개 대조. 독립 실험 8번이 아님 | "8개 대조 모두 예상 방향" |
| "v3.3이 더 정확하다" | #15의 0.421 → 0.606 차이 구간이 0을 포함 | "버전마다 같은 기준으로 재검증" |
| "복지 사각지대 96곳" | 30곳은 원자료 인구 0. 보류 사유가 다양 | "판단 보류" |
| "157곳은 고령 독거 고위험 지역" | watch에 중장년 테마 포함. B만 상위인 곳 66곳 | "두 축이 겹치는 곳" |
| "노후주택을 비아파트로 한정했다" | `oldho` = 노후주택 비율 × 비아파트 비율. 교차 집계가 아님 | "비아파트 비율을 곱한 대리지표" |
| 효과 수치("발굴률 ○% 향상" 등) | 시뮬레이션·효과 검증을 하지 않았다 | 에이전트 동작 설계로 제시 |

#### 1-1번 상세 — 사회적 고립이란?

**왜 넣나.** 1번 오프닝 질문 뒤, 2번 수치로 가기 전에 "무엇을 고립이라고 부르는지"를 먼저 정한다. 그래야 2번의 33.0%, 6번의 특징 24개, 7번의 "1인가구는 대리지표" 각주가 같은 정의 위에서 읽힌다.

- **13.6%의 정의는 위 정의와 다르다.** 논문은 2021년 서울시 1인가구 실태조사 방문면접 3,079명에서 "정서적·신체적·경제적 도움을 청할 사람이 한 명도 없는 경우"를 고립으로 봤다(통계청 정의보다 엄격). 카드 ② 아래에 "논문 정의 기준" 한 줄을 붙인다. 수치는 논문 초록에서 확인(외로움 62.1%, 고립 13.6%, 10/24).
- **카드 ①·②가 같은 논문 숫자를 쓴다.** 겹쳐 보이면 ①은 "느낌 대 관계" 문장만 두고 숫자는 ②에만 둔다.
- **카드 ③ "배"의 뜻:** 오즈비라 엄밀히는 "사망할 확률이 1.29배"가 아니라 "사망 오즈가 1.29배"다. 슬라이드에는 "사망 가능성 1.29배(약 29% 높음)"로 쓰고, 질문이 오면 오즈비라고 답한다. 세 값은 서로 다른 연구 묶음의 평균이라 서로 더하거나 비교 순위를 매기지 않는다(저자도 고립과 외로움을 바꿔 쓸 수 있다는 뜻이 아니라고 밝힘).
- **카드 ③ 표현:** "OR"이나 "오즈비"는 쓰지 않고 "배"로 쓰되, 질의응답 준비에 "교란요인을 통제한 연구들의 오즈비"라고 적어 둔다.
- **2번과 겹치지 않게:** 33.0%(사회적 고립도 값)는 2번 카드 ①에서만 쓴다. 여기서는 정의만 준다. 2번 발표 멘트를 "방금 본 정의로 재면, 성인 3명 중 1명이 해당합니다"로 시작하면 자연스럽게 이어진다.
- **연령 근거(선택):** 같은 지표에서 60세 이상 39.4%, 19~29세 24.4%(2025). 우리가 고령에 집중하는 이유로 10번 멘트에서 쓸 수 있다.
- **사진:** 참고 이미지(고층 아파트 야경)는 2번 카드 ③("고독사 77.5%가 아파트 밖")과 어긋나 보일 수 있다. 다세대·주택가 야경이나 1번 오프닝과 같은 사진을 흐리게 쓰는 쪽을 권한다.
- **근거 문서:** `docs/methodology/prior-research.md` 6·7·8절.

#### 2번 상세 — 문제 제기

**전달할 것 한 문장:** 고립된 사람은 도움을 청하지 않고 가족도 모르기 때문에, 신청을 기다리지 말고 위험이 모이는 곳을 먼저 찾아야 한다.

**초안(10/24 pptx)에서 바꿀 점.** 초안 카드(사망자 3,924명 / 남성 81.7% / 50·60대 62.9%)는 "누가 고독사하는가"를 보여 준다. 헤드라인은 "늦게 발견된다"인데 카드에는 발견에 관한 수치가 없고, 성별은 우리 분석에 쓰지 않는 변수라 다음 장으로 이어지지 않는다. 카드를 **도움 요청 → 발견 → 장소** 순서로 바꿔 세 장이 한 줄의 논리가 되게 한다.

| 카드 | 큰 숫자 | 아래 한 줄 | 말하는 것 | 다음 장 연결 |
|---|---|---|---|---|
| ① 청하지 않는다 | **33.0%** | 성인 3명 중 1명, 도움이 필요할 때 도움받을 곳이 없다 | 신청은 도움을 청할 수 있는 사람만 한다 | 신청주의의 빈틈 |
| ② 가족도 모른다 | **26.6%** | 고독사 최초 발견자 중 가족 비중 (2020년 34.8%). 임대인·경비원 등이 43.1%로 가장 많다 | 가까운 사람보다 집 주변 사람이 먼저 발견한다 | 개인이 아니라 **사는 곳**에서 찾는다 |
| ③ 사는 곳에 모인다 | **77.5%** | 고독사 발생 장소 중 아파트 외 주거 (주택 48.9%, 원룸·오피스텔 19.6%, 고시원 4.8%, 여관·모텔 4.2%) | 위험은 특정 주거 환경에 몰린다 | 7번 테마 B(주거)·집계구 단위 |

- **결론 줄(카드 아래):** "먼저 찾아가는 발굴이 필요하다" → 3번(같은 동 안의 차이)으로 넘어간다.
**레이아웃 (참고: 세종시 C.P.A "01 분석 필요성" 장).** 왼쪽에 헤드라인, 오른쪽에 같은 크기의 사진 카드 3장, 아래 화살표와 결론 한 줄을 둔다. 초안처럼 카드마다 형식(사진 / 제목 띠 / 숫자만)을 다르게 하지 않고 세 장을 똑같이 만든다.

```
┌──────────────┬──────────┬──────────┬──────────┐
│ 고립은        │[도움 공백]│[늦은 발견]│[주거 취약]│  ← 남색 제목 띠
│ 스스로        │  사진     │  사진     │  사진     │  ← 흑백 + 남색 반투명
│ 드러나지      │ 성인 3명중 │ 고독사 최초│ 고독사    │
│ 않습니다.     │ 1명       │ 발견자    │ 발생 장소 │  ← 사진 위 흰 글씨 2줄
│ 신청을 기다리지│ 도움받을 곳│ 가족은    │ 77.5%가  │     (둘째 줄 굵게)
│ 않고 먼저 찾아 │ 이 없다   │ 26.6%뿐  │ 아파트 밖 │
│ 야 하는 이유   │          │          │          │
├──────────────┴──────────┴──────────┴──────────┤
│                     ▼                          │
│        위험이 모이는 곳부터 먼저 찾는다           │  ← 결론 (가장 큰 글씨)
│ 출처 각주                                       │
└────────────────────────────────────────────────┘
```

| 자리 | 문구 |
|---|---|
| 왼쪽 큰 글씨 | 고립은 **스스로** 드러나지 않습니다. |
| 왼쪽 작은 글씨 | 도움 요청을 기다릴 수 없는 이유 (Canva 초안 "신호를 기다리지말고 먼저 찾아야하는 이유"는 띄어쓰기 오류 + 결론과 같은 말 반복) |
| 카드 ① 제목 띠 / 본문 | **도움 공백** / 성인 3명 중 1명 · **도움받을 곳이 없다** |
| 카드 ② 제목 띠 / 본문 | **늦은 발견** / 고독사 최초 발견자 · **가족은 26.6%뿐** (작게: 임대인·경비원 43.1%) |
| 카드 ③ 제목 띠 / 본문 | **주거 취약** / 고독사 발생 장소 · **77.5%가 아파트 밖** |
| 화살표 아래 결론 | **먼저 찾아가는 발굴**이 필요하다 (10/25 변경. "위험이 모이는 곳을 먼저 찾자"는 청유형이라 어색) |
| 하단 각주 | 출처: 보건복지부, 2024년도 고독사 발생 실태조사(2025.11). ①은 같은 자료가 인용한 통계청 사회조사(2023). ②·③은 고독사 사망자 특성이며 고립 유병률과 다르다. |

- **사진:** 사람 얼굴이나 쓰러진 사람·술병처럼 고독사 현장을 연상시키는 사진은 쓰지 않는다. 초안 1번 카드 그림이 여기에 해당한다(낙인·자극 우려). 사람이 없는 장면으로 고른다: ① 불 꺼진 방의 휴대폰·빈 의자 ② 우편물·전단이 쌓인 현관문 ③ 다세대·원룸 골목 야경. 세 장 모두 흑백 + 남색 반투명을 덮어 톤을 맞추고, 출처(Unsplash 등)는 슬라이드 노트에 적는다.
- **숫자 표기:** 사진 위 글씨가 작아지므로 큰 숫자 카드 대신 레퍼런스처럼 "문장 + 굵은 숫자"로 쓴다. 3,924명은 카드에 넣지 않고 발표 첫 문장으로 말한다.
- **발표 멘트 보강:** 정부도 2026년부터 지자체 발굴조사를 다세대·원룸·고시원 밀집 지역 위주로 하도록 안내한다(같은 보도자료). 우리 접근이 정책 방향과 같다는 근거로 말로만 덧붙인다.
- **각주:** "출처: 보건복지부, 2024년도 고독사 발생 실태조사(2025.11). ①은 같은 자료가 인용한 통계청 사회조사(2023). ②·③은 고독사 사망자 특성이며 고립 유병률과 다르다."
- **초안 카드는 빼되 버리지 않는다.** 3,924명(전년 대비 7.2% 증가)은 발표 멘트 첫 문장("작년 고독사는 3,924명")으로, 50·60대 62.9%는 질의응답 준비로 보낸다(테마 A의 `solo50`이 50세 이상을 쓰는 근거). 남성 81.7%는 쓰지 않는다. 성별을 분석에 쓰지 않았기 때문이다.
- **쓰지 않는 표현:** "아파트 외 주거가 고립을 일으킨다"(인과 아님), "고독사 위험 지역을 찾았다"(우리 결과는 고립 위험 대리지표).
- **[확인]** ① 33.0%는 보도자료 인용값이다. 지표누리 「사회적 고립도」(index.go.kr, idxCd=8080) 원표에서 2023년 값을 대조한다. 정의: 집안일 부탁·이야기 상대 중 하나라도 도움받을 곳이 없는 19세 이상 비율.

#### 3번 상세 — 왜 집계구인가

**바꾼 이유.** 초안의 "1등급과 5등급 집계구가 함께 있는 동 11/22"는 우리 지수가 만든 등급이다. "문제 정의"에서 우리 결과로 필요성을 주장하면 순환 논리가 된다(결과로 방법을 정당화). 01장은 **분석 전에도 누구나 확인할 수 있는 사실**만 쓴다.

**전달할 것 한 문장:** 동 평균 하나로는 동 안의 차이가 지워진다. 그래서 더 작은 단위(집계구)로 봐야 한다.

**근거 (SGIS 2024 원자료, 1인가구 ÷ 총가구).** 결측·가구 0을 뺀 집계구 1,639곳 (전체 1,698곳). 범위는 극단값 대신 하위 10%~상위 10%로 쓴다.

| 동 | 동 전체 | 집계구 수 | 집계구 범위 (P10~P90) |
|---|---:|---:|---|
| 강남 역삼2동 | 36.5% | 72 | 5.0% ~ 71.7% |
| 강남 세곡동 | 35.6% | 85 | 6.5% ~ 71.4% |
| 춘천 석사동 | 38.7% | 68 | 11.3% ~ 68.2% |
| 춘천 퇴계동 | 29.7% | 94 | 6.9% ~ 58.0% |

- 같은 동 안에서 집계구 1인가구 비율의 차이(상위 10% 집계구 값 − 하위 10% 집계구 값)가 30%p 이상인 동: 강남 14/22, 춘천 12/25. 차이의 중앙값은 강남 40.5%p, 춘천 28.9%p.
- 동 하나에 집계구가 강남은 중앙값 45개, 춘천은 14개다.

**레이아웃 (참고: 세종시 C.P.A "공간 통계 기반 분석 필요" 장).** 지도를 배경으로 깔고, 그 위에 흰 카드 3장을 세로로 쌓아 굵은 세로 막대로 잇는다. 마지막 카드 아래 큰 화살표와 결론을 둔다. 카드마다 제목 한 줄 + 본문 두 줄이고, 본문의 핵심어만 강조색이다.

```
┌──────────────────────────────────────────────────────┐
│ 01 문제 정의                                         │

│                                                      │

```

| 자리 | 문구 (굵게 = 강조색) |

- **카드 개편(10/25): 왼쪽 역삼2동 지도를 읽어 주는 이야기로 바꾼다.** 추상적 근거("차이의 61%", "통계가 붙는 최소 단위", 해외 선례)는 와닿지 않아 슬라이드에서 뺀다(정연 검토).

  | 카드 | 제목 | 본문 |

  | ② | 평균은 아무도 아니다 | 동 평균은 36.5%지만, 그 근처에 사는 가구는 **5%뿐** |

#### 7~11번 연결 — 축마다 "만들기 → 결과 → 검증"으로 묶는다

**문제(10/24 Canva 초안 기준).** 지금 순서는 8 축 1 결과 → 9 축 2 방법 → 10 축 2 검증 → 11 축 1 검증이다. 축 1의 결과(8)와 검증(11) 사이에 축 2가 끼어 있어, 11번에서 "지수"가 다시 나올 때 듣는 사람이 7·8번을 다시 떠올려야 한다. 10·11번은 같은 서울 통신 자료·같은 강남 22개 동을 쓰는데 왜 따로 떨어져 있는지도 설명되지 않는다.

**순서를 바꾼다.** 축마다 만들고 → 결과 보고 → 검증하고 넘어간다.

- **축 진행 표시(오른쪽 위 작은 띠):** `축 1 노출 [만들기·결과·검증] │ 축 2 활동 [만들기·검증] │ 교차`. 현재 장의 칸만 진하게. 4-1번 순서도의 "두 축 탐지" 칸 색(축 1·축 2 같은 계열 색)을 그대로 쓴다.

**문장 다듬기**
- 새 9번(지금 11번) 아래 "9개 대조 모두 양의 상관"은 새 11번의 "8개 대조"와 숫자가 달라 헷갈린다. 각주에 "축 1은 테마 3개 × 연령 기준 3개 = 9개 대조"를 붙인다.

## 9. 질의응답 준비

부록이 없으므로 아래 질문은 발표자가 수치로 바로 답할 수 있게 준비한다.

| 예상 질문 | 답의 핵심 | 출처 |
|---|---|---|
| 혼자 사는 고령자를 직접 센 것인가? | 아니다. 1인가구율 × 50세+ 비율 같은 대리지표. 연령 × 가구형태 교차표가 공개되지 않는다 | `docs/isolation_index_v3.md` |
