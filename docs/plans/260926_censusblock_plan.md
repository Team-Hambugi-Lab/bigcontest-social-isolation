## 1. 타당성 실측 근거

### 1.1 해상도별 노이즈

`BLOCK_CD` 자릿수를 집계구 규모의 대리로 두고 검정했다.

| 앞자리 | 단위 수 | 총유동 중앙값 | 5분위 | 고령비중 월간상관 | 월간 표준편차 중앙값 |

## 2. 제안의 문제점과 수정

### 문제 1 — 집계구 score를 만들면 정의와 끊긴다

경로 B에서 확인한 사실:

- 정의("대면 접촉 기회")와 연결된 축은 **카드에만** 있다 (α 0.720 통과)
- SK의 `night_share`는 **유입 역지수**다 (유입배수와 −0.850, 춘천 −0.973)
- SK 3테이블은 서로 교차 불가능한 주변분포다

집계구 score를 SK만으로 만들면 1차 설계의 실패를 더 잘게 쪼개 반복하게 된다.

**수정** — 집계구를 score 산출처가 아니라 **외부 데이터를 붙이는 그릇**으로 쓴다.

### 문제 2 — 축을 EDA로 고르면 안 된다

"집계구끼리 비교한 후 축 몇 개를 선정"은 1차 설계 방식이다. 결과는 α 0.271 / −4.219였다.

**수정** — 축은 정의에서 도출하고, 합산 전 Cronbach's α ≥ 0.7을 통과해야 한다.
이 규칙은 `src/features/contact.py`의 `coherence()`와 `tests/test_contact.py`에 이미 고정돼 있다.

### 문제 3 — 춘천 농촌 집계구의 불균등

14자리 기준 단위당 격자 수는 춘천 평균 150.8, 최대 3,739이다(강남 평균 14.2).
면 지역 집계구는 면적이 수십 ㎢에 달한다. 밀도 지표가 왜곡된다.

**수정** — 면적을 공변량으로 넣거나, 밀도 대신 구성비 지표를 쓴다.
도시/농촌 집계구를 층화해 비교한다.

## 3. 수정된 설계 — 정의를 두 조각으로 나눈다

> 고립 = 타인과 **대면 접촉**할 **기회**가 **구조적으로** 적은 상태

| 조각 | 담당 | 단위 | n | 재는 것 |
|---|---|---|---:|---|
| **기회의 공급** | SK + 통계청 집계구 통계 | 집계구 | 약 1,639 | 주변에 사람이 있는가, 갈 곳이 있는가 |
| **접촉의 실현** | 신한카드 | 지역×성×연령×월 | 216 | 실제로 대면 소비를 하는가 |

두 축은 합치지 않는다. 공간 해상도가 1,639 대 2로 다르기 때문이다(1차 설계의 이중 해상도 원칙 유지).
대신 **시군구 2개 수준에서 방향만 대조**하고, 각자의 축에서 우선순위를 낸다.

### 기회의 공급 — 집계구 축 후보

정의에서 도출되는 것만 넣는다. 각 항목이 정의의 어느 부분에서 나오는지 명시한다.

| 후보 | 정의와의 연결 | 출처 | 비고 |
|---|---|---|---|
| 상주인구 대비 유동인구 배수 | "기회" = 마주칠 사람의 수 | SK 심야유동 ÷ 주민등록인구 | 심야(02~04시)가 상주 근사임을 확인함 |
| 1인가구 비율 | "구조적" = 가구 내 접촉 부재 | 통계청 집계구 | 외부 |
| 65세 이상 고령가구 비율 | "구조적" | 통계청 집계구 | 외부 |
| 대면 업종 접근성 | "기회" = 갈 곳의 유무 | 공공데이터 상가업소 | 외부, 무료 |
| 복지시설 접근성 | 개입 가능성 | 공공데이터포털 | 외부, 무료 |

**중요** — 이 목록도 가설이다. 산출 후 반드시 `coherence()`로 일관성을 검정하고,
α < 0.7이면 합산하지 않는다.

## 4. 강남·춘천 관계 설정

### 선택지 평가

| 방식 | 평가 | 근거 |
|---|---|---|
| 완전 독립 분석 | 대조 가치 상실 | 주최 측이 대조적 지역 쌍을 준 의도에 부합하지 않음 |
| 전역 표준화 후 단일 순위 | **이미 실패** | 고령비중 상관 춘천 +0.663 / 강남 −0.370. 합치면 상쇄되어 전체 +0.286 |
| **지역 고정효과 + 구조 비교** | **채택** | 아래 |

### 채택안 상세

**① 지역은 고정효과로 둔다. 임의효과가 아니다.**
지역이 2개뿐이라 random effect의 분산 추정이 불안정하다.
집계구가 시군구에 중첩된 구조에서 지역 더미를 넣은 회귀가 적절하다.

**② 두 가지를 분리해 보고한다.**

| 구분 | 추정 대상 | 답하는 질문 |
|---|---|---|
| 수준 차이 | 지역 더미 계수 | 춘천이 강남보다 평균적으로 위험한가 |
| **구조 차이** | 지역별 계수 비교 | **위험을 만드는 요인이 두 지역에서 같은가** |

**③ 핵심은 구조 차이다.**
지역별로 같은 모형을 적합하고 계수를 비교하면, V4 부호 반전이 결함이 아니라
**"도시형 고립과 농촌형 고립은 위험 요인이 다르다"**는 발견이 된다.

n=47일 때는 불가능했다. n=1,639(강남 1,082 / 춘천 557)면 지역별로도 추정된다.
**집계구 전환의 진짜 가치가 여기 있다.**

**④ 순위는 지역 내에서 낸다.**
수준 차이가 존재하므로 1,639개를 한 줄로 세우지 않는다.
대회 요건 "우선지원 지역·계층 도출"은 지역별 순위로 충족한다.

## 5. 실행 계획

### Step 0 — 집계구 경계 확보 (선행, 사용자 작업 필요)

| 항목 | 출처 | 형식 |
|---|---|---|
| 집계구 경계 shapefile (강남구·춘천시) | SGIS 자료제공 또는 공공데이터포털 | SHP, EPSG:5179 |
| 집계구별 총인구·세대수 | 인구주택총조사 소지역 통계 | CSV |
| 집계구별 1인가구 수 | 인구주택총조사 | CSV |
| 집계구별 65세 이상 인구 | 인구주택총조사 | CSV |

**전부 무료 공개다.** 다만 SGIS는 신청 절차가 있어 제가 받을 수 없다.
`data/external/`에 넣어 주시면 이후를 진행한다.

경계 shapefile이 EPSG:5179면 우리 좌표와 좌표계가 같아 변환 없이 조인된다.

### Step 1 — 공간조인과 단위 확정

| 작업 | 산출물 | 검증 |
|---|---|---|
| SK 격자 좌표 → 집계구 공간조인 | `src/data/census_block.py` | 미매칭 격자 비율 < 1% |
| 집계구별 격자 수·면적 분포 확인 | 노트북 | 격자 3개 미만 집계구 처리 규칙 결정 |
| 집계구 × 월 패널 구축 | `src/features/sk_block.py` | 3테이블 커버리지 일치 확인 |
| `BLOCK_CD` 14자리와 대조 | 리포트 | 두 체계의 일치도 측정 |

**중단 조건** — 미매칭 격자가 5%를 넘으면 좌표계나 경계 버전을 재확인한다.

### Step 2 — 기회의 공급 축 산출과 일관성 검정

| 작업 | 검증 |
|---|---|
| 정의에서 도출한 후보 축 산출 | 각 축이 정의의 어느 부분에서 나오는지 문서화 |
| **`coherence()` 검정** | **α ≥ 0.7 미달 시 합산하지 않고 정의로 복귀** |
| 월 간 신뢰도 | Spearman ≥ 0.85 |
| 음의 대조 | 집계구 면적·총유동과의 상관이 강하면 재설계 |
| 도시/농촌 층화 재검정 | 지역별 α 확인 |

**이 단계를 통과하지 못하면 Step 3으로 가지 않는다.**

### Step 3 — 지역 고정효과 모형

| 작업 | 내용 |
|---|---|
| 기술 통계 | 집계구 단위 분포, 지역별 차이 |
| 고정효과 회귀 | 결과변수 ~ 축들 + 지역더미 (+ 면적·인구 통제) |
| 지역별 개별 적합 | 계수 비교로 구조 차이 검정 |
| 계수 차이 유의성 | 교호작용항 또는 Chow 검정 |

### Step 4 — 카드 집단축 병행 확정

경로 B에서 α 0.720으로 통과한 축을 확정 산출한다.
집계구 축과 합치지 않고, 시군구 2개 수준에서 방향만 대조한다.

### Step 5 — 외부 검증과 심한 고립 정의

| 작업 | 내용 |
|---|---|
| 집계구 축 ↔ 1인가구·고령가구 비율 상관 | **지역별로 따로** 본다 (전체로 하면 부호 상쇄) |
| 부호가 예상과 다른 축 재설계 | |
| 심한 고립의 소재 정의 | 고독사 통계, 은둔형 외톨이 실태조사 등 |
| 조기 단계 ↔ 심한 고립의 방향 일치 확인 | 진행을 주장하지 않고 연속선상만 주장 |

## 7. 이 계획이 해결하는 것과 못 하는 것

**해결하는 것**

- n = 47 → 약 1,639. 지역별 모형 적합과 구조 비교가 가능해진다
- 통계청 인구 통계 직접 조인으로 **방향성 검증의 길이 열린다**
- V4 부호 반전을 결함이 아니라 발견으로 전환할 수 있다
- 카드 집단축을 버리지 않는다

**못 하는 것**

- 카드는 여전히 시군구 2개다. 공간축과 집단축은 끝까지 합칠 수 없다
- SK 3테이블의 교차 불가 제약은 그대로다 (평일 야간, 연령별 시간대 산출 불가)
- 소비도 이동도 없는 심한 고립자는 여전히 데이터에 없다
- "조기 단계 → 심한 고립" 진행은 횡단 데이터로 증명 불가
