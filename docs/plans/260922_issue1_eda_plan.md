# [EDA] 제공 데이터 탐색 및 고립 신호 가설 도출 계획 — 2026-09-22

## 1. 목적

SKT 유동인구와 신한카드 주제2 결제 데이터의 구조와 품질을 검증하고, 강남구·춘천시의 지역·인구집단 단위 사회적 고립 위험 신호로 발전시킬 수 있는 가설 후보를 도출한다.

이번 단계의 목표는 위험도를 확정하거나 예측 모델을 만드는 것이 아니다. 데이터에서 반복 확인할 수 있는 패턴과 그 한계를 기록해 후속 지표 설계의 근거를 마련한다.

| 구분 | 범위 |

### 4.5 인구계층 기반 고립 의심 신호 탐색

현재 데이터로 개인의 고립 여부를 판정할 수는 없다. 아래 분석은 특정 지역·성별·연령 집단에서 나타나는 **집단 수준의 고립 의심 신호**를 찾는 데 한정한다.

#### 공통 분석 단위

SKT와 신한카드는 다음 공통 키로 각각 집계한 뒤 비교한다.

```text
기준월 × 지역 × 성별 × 연령대
```

- 지역: `서울 강남구`, `강원 춘천시`
- 성별: `남성`, `여성`
- 연령대: `10대`, `20대`, `30대`, `40대`, `50대`, `60대 이상`
- 신한카드의 60~90대는 SKT의 `60대 이상` 기준에 맞춰 통합한다.
- 두 데이터는 같은 개인을 연결하지 않으며, 공통 키는 집단별 분포와 변화 방향을 비교하는 용도로만 사용한다.

#### 1. 인구계층 구성

- [ ] 지역별 연령대·성별 유동인구 비중 계산
- [ ] 강남구와 춘천시의 계층 구성 차이 비교
- [ ] 월별 구성비 변화 확인
- [ ] 특정 계층의 유동인구만 지속해서 감소하는지 확인

```text
연령대 유동인구 비중 = 해당 연령대 유동인구 / 전체 유동인구
```

지역 규모 차이가 크므로 절대 유동인구와 지역 내 구성비를 함께 본다.

#### 2. 계층별 활동 감소

- [ ] 전월 대비 유동인구 증감률
- [ ] 6개월 내 최고치 대비 감소율
- [ ] 2개월 이상 연속 감소 여부
- [ ] 지역 전체 유동인구와 반대 방향으로 움직이는 계층 확인
- [ ] 같은 지역의 다른 연령대보다 감소폭이 큰 계층 확인

예를 들어 춘천시 전체 유동인구는 유지되는데 60대 이상만 계속 감소한다면 계층 특이 신호 후보로 기록한다.

#### 3. 소비활동 감소

- [ ] 결제건수와 결제금액의 월별 변화
- [ ] 건당 결제금액(`결제금액 / 결제건수`)
- [ ] 결제건수와 금액의 동반 감소 여부
- [ ] 특정 계층에만 나타나는 감소인지 확인
- [ ] 감소가 2개월 이상 지속되는지 확인

`USE_CNT`는 고객 수가 아니라 결제건수이므로 이용자 수 감소로 해석하지 않는다.

#### 4. 소비 업종 다양성

- [ ] 이용 업종 수
- [ ] 업종별 결제건수 구성비
- [ ] 상위 1개·3개 업종 집중도
- [ ] 업종 다양성 지수
- [ ] 생활필수 업종과 사회활동 업종의 비중

전체 소비가 유지되더라도 이용 업종이 소수 생활필수 업종에 집중된다면 활동 범위 축소 가능성을 검토한다. 단, 개인별 업종 다양성이 아닌 집단 수준의 다양성으로만 해석한다.

#### 5. 이동과 소비의 동반 변화

| 유동인구 | 결제건수 | 해석 후보 |
| --- | --- | --- |
| 감소 | 감소 | 활동·소비 동반 위축 |
| 감소 | 유지 | 이동 감소 또는 지역 내 소비 집중 |
| 증가 | 감소 | 방문 증가와 소비 감소가 혼재 |

한 지표만 감소한 집단보다 `유동인구 감소 + 결제건수 감소 + 업종 다양성 감소`가 2개월 이상 함께 나타나는 집단의 검토 우선순위를 높인다.

#### 6. 고객 거주지 구성

- [ ] 가맹점 지역별 고객 거주지 구성비
- [ ] 서울·강원 거주자의 소비 비중 변화
- [ ] 외지 거주자 소비 감소가 지역 주민 소비 감소처럼 보이는지 확인
- [ ] `정보없음` 비율의 월별 변화

`CLN_SGG_CD`는 시도 단위이므로 강남구 주민과 서울의 다른 구 주민을 구분할 수 없다.

#### 7. 시간·요일 활동 패턴

- [ ] 주말/평일 유동 비율
- [ ] 야간/주간 유동 비율
- [ ] 평일과 주말의 활동 차이
- [ ] 특정 시간대 활동 감소
- [ ] 월별 생활 리듬 변화

SKT의 성연령·시간대·요일 데이터는 별도 테이블이며 교차 차원이 제공되지 않는다. 따라서 `60대 이상의 야간 유동인구`, `20대 여성의 주말 유동인구`처럼 연령·성별과 시간·요일을 교차한 값은 계산하지 않고, 시간·요일 분석은 전체 유동인구 수준에서 수행한다.

#### 8. 외부 취약성 지표 결합

- [ ] 연령별 1인 가구 비율
- [ ] 복지시설 접근성
- [ ] 고립·은둔 실태조사의 주요 위험 요인

외부 지표는 제공 데이터의 의심 신호를 보강하는 용도로 사용하며, 개인 수준 위험 요인을 지역 집계 데이터의 확정 판정 기준으로 사용하지 않는다.

### 4.6 핵심 검증 질문과 분석 우선순위

다음 질문에 순서대로 답한다.

1. 춘천시 고령층 유동인구 비중이 월별로 감소하는가?
2. 유동인구가 감소한 성·연령 집단에서 카드 결제건수도 감소하는가?
3. 특정 계층의 소비 업종 다양성이 지속해서 줄어드는가?
4. 이동·소비 감소가 전체 지역 변화가 아니라 특정 계층에 집중되는가?
5. 외지 고객 감소와 지역 주민 활동 감소를 구분할 수 있는가?
6. 고령 1인 가구 비율이 높은 지역에서 유동 감소 신호가 더 크게 나타나는가?

분석 우선순위는 다음과 같다.

```text
성별·연령 분포
→ 계층별 월간 증감
→ 결제건수·금액 변화
→ 업종 다양성
→ 이동·소비 동반 신호
→ 외부 취약성 지표 결합
```

가설마다 관측 단위와 계산식, 근거 표·그래프, 지역별 방향과 크기, 고립 외의 대안 설명, 추가 필요 데이터와 현재 검증 가능 범위를 기록한다. 결론은 다음 수준으로 제한한다.

> 특정 지역·인구집단에서 이동·소비·활동 다양성의 동반 위축 신호가 관측됐다. 다만 개인의 고립 여부를 직접 의미하지 않으며 인구 변화, 계절, 날씨 등 대안 설명을 추가로 검증해야 한다.

## 5. 외부 참고자료 확인

외부 참고자료는 제공 데이터에서 관측한 패턴의 의미를 해석하거나 지표 후보를 찾는 데 사용한다. 직접 결합하기 전 다음을 확인한다.

- [ ] 제공 기관, 원본 URL, 수집일, 이용 조건
- [ ] 조사 모집단, 표본설계, 가중치와 조사 시점
- [ ] 고립·은둔 정의와 설문 문항
- [ ] 강남구·춘천시 또는 비교 가능한 지역 식별 가능 여부
- [ ] 제공 데이터와 연령·성별·지역 단위가 호환되는지 확인
- [ ] 원자료와 집계표를 중복 증거로 세지 않기

외부 조사에서 확인한 개인 수준 위험 요인을 지역 집계 데이터에 그대로 대입하지 않는다. 지표의 이론적 근거 또는 후속 검증 자료로 구분한다.

## 6. 시각화 기준

- 그래프에 제목, 축 이름, 단위, 범례를 표시한다.
- 색약 친화 팔레트를 사용하고 강남구·춘천시 색상을 일관되게 유지한다.
- 절대값과 구성비 또는 변화율을 구분한다.
- 복잡한 그래프에는 같은 값을 확인할 수 있는 요약표를 함께 둔다.
- 통계 수치는 소수점 셋째 자리, 비율은 소수점 첫째 자리까지 표시한다.
- 관측되지 않은 값을 0으로 대체하지 않는다.
