# [EDA] 제공 데이터 탐색 및 고립 신호 가설 도출 계획 — 2026-09-22

## 1. 목적

SKT 유동인구와 신한카드 주제2 결제 데이터의 구조와 품질을 검증하고, 강남구·춘천시의 지역·인구집단 단위 사회적 고립 위험 신호로 발전시킬 수 있는 가설 후보를 도출한다.

이번 단계의 목표는 위험도를 확정하거나 예측 모델을 만드는 것이 아니다. 데이터에서 반복 확인할 수 있는 패턴과 그 한계를 기록해 후속 지표 설계의 근거를 마련한다.

## 2. 분석 범위

| 구분 | 범위 |
| --- | --- |
| 기간 | 2025년 7월~12월 |
| 지역 | 서울 강남구, 강원 춘천시 |
| SKT | 성연령·시간대·요일별 격자 유동인구 18개 CSV |
| 신한카드 | 주제2 데이터셋2 TXT만 사용 |
| 분석 단위 | 비식별 지역·인구집단 집계 |
| 외부 참고자료 | 서울시·보건복지부 고립은둔청년 실태조사, 서울 29개 통신정보 |

### 제외 범위

- 신한카드 주제1 데이터셋2를 주 분석에 혼합하지 않는다.
- 개인의 사회적 고립 여부를 판정하지 않는다.
- 상관관계를 인과관계로 해석하지 않는다.
- 위험지수, 예측 모델, AI 에이전트 구현은 이번 이슈에서 다루지 않는다.

## 4. 실행 순서

### 4.1 파일과 스키마 점검

- [ ] 분석 대상 파일 목록, 크기, 수정 시각 기록
- [ ] 파일명에서 기대하는 기간과 실제 기간 비교
- [ ] 구분자와 인코딩 확인
- [ ] 파일별 행·열 수와 컬럼 순서 기록
- [ ] 같은 테이블의 월별 스키마 일치 여부 확인
- [ ] 숫자형·문자형·날짜형 변환 가능 여부 확인
- [ ] 원본은 수정하지 않고 읽기 전용으로 사용

### 4.2 SKT 데이터 품질 점검

- [ ] `STD_YM`이 파일명의 기준월과 일치하는지 확인
- [ ] `STD_YM`, `BLOCK_CD`, `X_COORD`, `Y_COORD` 기본 키 중복 확인
- [ ] `BLOCK_CD` 길이와 월별 고유 개수 확인
- [ ] 좌표 결측, 중복, 최소·최대 범위 확인
- [ ] 유동인구 컬럼의 결측, 음수, 무한대, 비정상적으로 큰 값 확인
- [ ] 성연령·시간대·요일 테이블별 월간 행 수와 격자 집합 비교
- [ ] 2025년 7월~12월 사이 사라지거나 새로 생긴 격자 확인
- [ ] 성연령 합계, 시간대 합계, 요일 합계의 규모 차이 확인

세 테이블의 값은 서로 다른 기준의 일평균일 수 있으므로 합계가 같다고 가정하지 않는다. 정의서에서 산출 기준을 확인한 뒤 비교한다.

### 4.3 SKT 공간 범위 점검

- [ ] `X_COORD`, `Y_COORD`가 UTM-K(EPSG:5179)인지 확인
- [ ] 강남구·춘천시 행정경계의 출처, 기준 시점, 좌표계 기록
- [ ] SKT 좌표를 두 지역 경계와 공간 조인
- [ ] 지역별 격자 수와 매핑 성공률 계산
- [ ] 경계 밖, 경계선, 결측·중복 좌표 건수 확인
- [ ] 월별·테이블별 공간 범위가 일관적인지 확인
- [ ] `BLOCK_CD` 앞자리로 행정구역을 추정하지 않기

행정경계가 준비되지 않았다면 좌표 분포와 범위까지만 기록하고, 공간 조인 결과는 보류로 명시한다.

### 4.4 신한카드 주제2 데이터 품질 점검

- [ ] `TA_YMD`를 날짜형으로 변환하고 2025년 7월~12월 범위 확인
- [ ] `MCT_SGG_CD`가 `서울 강남구`, `강원 춘천시` 두 값인지 확인
- [ ] `SEX_CCD`, `AGE_CCD`에 `법인` 값이 없는지 확인
- [ ] `TS_AT`, `USE_CNT`를 숫자형으로 변환하고 실패 건수 기록
- [ ] `CLN_SGG_CD` 결측률과 `정보없음` 비율을 구분해 확인
- [ ] 성별·연령대·거주지·업종의 고유값과 빈도 확인
- [ ] `AGE_CCD`의 공백 등 원본 표기 규칙 확인
- [ ] 예상 집계키 기준 중복 여부 확인
- [ ] 결제금액·건수의 0, 음수, 극단값 확인
- [ ] 일자·지역별 행 수 급변 또는 누락일 확인

### 4.5 기본 EDA

다음 비교를 우선 수행한다.

1. 강남구와 춘천시의 월별 전체 유동인구·결제금액·결제건수 추이
2. 성별·연령대별 유동인구 및 소비 구성비
3. 평일·주말 및 시간대별 유동인구 패턴
4. 업종별 결제금액, 결제건수, 건당 결제금액
5. 고객 거주지별 소비 구성비와 `정보없음` 비율
6. 월별 증감률과 지역 내부 기준선 대비 편차

지역 규모가 다르므로 절대값만 비교하지 않는다. 지역별 구성비, 전월 대비 변화, 각 지역 내부 표준화 값을 함께 본다. 시점이 6개월뿐이므로 계절성이나 장기 추세로 단정하지 않는다.

### 4.6 고립 신호 가설 후보 도출

다음은 검증 대상 예시이며 사전에 사실로 가정하지 않는다.

| 후보 신호 | 확인할 패턴 | 주요 대안 설명 |
| --- | --- | --- |
| 야간·주말 활동 감소 | 특정 지역·연령층의 지속적인 유동 감소 | 계절, 날씨, 휴일, 상권 변화 |
| 생활 소비 위축 | 결제건수와 생활밀착 업종 소비의 동반 감소 | 물가, 소득, 업종 구성 변화 |
| 활동 다양성 감소 | 이용 업종 구성의 편중 또는 다양성 하락 | 지역 상권 구조 차이 |
| 외부 교류 약화 | 외지 거주자 소비 비중 변화 | 관광·통근·행사 효과 |
| 이동·소비 동반 감소 | 같은 지역·집단에서 두 신호가 동시에 하락 | 집계 단위 불일치, 계절 효과 |

가설마다 다음을 기록한다.

- 관측 단위와 계산식
- 근거 표·그래프
- 강남구·춘천시에서의 방향과 크기
- 고립 외의 대안 설명
- 추가로 필요한 외부 데이터
- 현재 데이터로 검증 가능한 범위

## 5. 외부 참고자료 확인

외부 참고자료는 제공 데이터에서 관측한 패턴의 의미를 해석하거나 지표 후보를 찾는 데 사용한다. 직접 결합하기 전 다음을 확인한다.

- [ ] 제공 기관, 원본 URL, 수집일, 이용 조건
- [ ] 조사 모집단, 표본설계, 가중치와 조사 시점
- [ ] 고립·은둔 정의와 설문 문항
- [ ] 강남구·춘천시 또는 비교 가능한 지역 식별 가능 여부
- [ ] 제공 데이터와 연령·성별·지역 단위가 호환되는지 확인
- [ ] 원자료와 집계표를 중복 증거로 세지 않기

외부 조사에서 확인한 개인 수준 위험 요인을 지역 집계 데이터에 그대로 대입하지 않는다. 지표의 이론적 근거 또는 후속 검증 자료로 구분한다.

## 6. 시각화 기준

- 그래프에 제목, 축 이름, 단위, 범례를 표시한다.
- 색약 친화 팔레트를 사용하고 강남구·춘천시 색상을 일관되게 유지한다.
- 절대값과 구성비 또는 변화율을 구분한다.
- 복잡한 그래프에는 같은 값을 확인할 수 있는 요약표를 함께 둔다.
- 통계 수치는 소수점 셋째 자리, 비율은 소수점 첫째 자리까지 표시한다.
- 관측되지 않은 값을 0으로 대체하지 않는다.

## 8. 알려진 한계

- 제공 데이터는 강남구·춘천시만 포함하므로 전국 일반화를 검증할 수 없다.
- 집계 데이터이므로 개인의 고립 상태나 행동 경로를 식별할 수 없다.
- 6개월 자료만으로 장기 추세와 계절성을 분리하기 어렵다.
- SKT와 신한카드의 공간·시간·인구집단 단위가 달라 직접 행 단위 결합은 불가능하다.
- 실제 고립 여부를 나타내는 정답 레이블이 없어 탐색 결과는 위험 신호 후보에 해당한다.
