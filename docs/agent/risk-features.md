# 고립 위험 특징 사전 근거 (#17)

에이전트의 1 분류(특징 코드 부여)와 4 추천(기관 태그 매칭), 지역 지수 차원(#13)이 같은 어휘를 쓰도록 만든 위험 특징 사전의 근거를 정리한다. 사전은 점수를 내는 지수가 아니라 **가중치 없는 분류표**다. 특징마다 해당 여부만 판정한다.

- 청년 작업본(A-1): [`data/interim/risk_features_youth.csv`](https://drive.google.com/file/d/1x3dQp3So3m9el33gPcz1Z6yZXJmdTeV_/view)(근거 수치), [`data/interim/risk_feature_dictionary_youth.csv`](https://drive.google.com/file/d/1X9XWkXRkms5QiQv5JtNq3yEK68En0lAY/view)(사전 청년 행)
- 고령·중장년 작업본(A-2): [`data/interim/risk_features_senior.csv`](https://drive.google.com/file/d/1fHzqntTdQbKEOUZuBXMPXF9c09FU9f2-/view)(특징 12개), [`data/interim/risk_features_senior_evidence.csv`](https://drive.google.com/file/d/1noUpUJ_M_xFz_oQVDEHneDbHOHK_weMs/view)(근거 수치), [`data/interim/proposed_senior_features.csv`](https://drive.google.com/file/d/1NsrkS4ZbUdGwWMxYeoV3nEhiZR_L35r_/view)(신규 코드 후보 3개). 전체 목록은 아래 "고령·중장년 근거 (A-2)" 표

- 사전의 행은 범주 아래의 특징이다(예: `MIND_SUICIDE_IDEA`).
- 같은 특징이 연령별로 다르면 범주를 나누지 않고 `AGE_PATTERN`에 적는다.
- `BODY`는 고령 문항이 맞지 않으면 `HEALTH`와 `LIFE`로 나누기로 했으나, A-2 검토는 **유지**를 권한다(아래 "BODY 범주 의견"). 팀 확정 대기.

**특징 정의는 "지금 감지하는 상태" 기준이다.** 사전은 설문 응답자를 분류하는 표가 아니라, 에이전트가 사용자에게서 지금 감지한 특징을 분류하는 표다. 설문 비율은 그 특징이 왜 중요한지 보여 주는 근거일 뿐이다. 정의와 근거를 섞으면 결정이 흔들린다(아래 `IS_CRISIS` 참고).

**`IS_CRISIS` 기준:** 생명이나 안전에 즉각 위험이 되는 특징만 위기로 본다. 판단이 애매하면 위기 쪽으로 둔다.
- 위기 특징은 `MIND_SUICIDE_IDEA`(지난 2주 안의 자살·자해 생각)와 `MIND_SUICIDE_ATTEMPT`(지난 2주 안의 자살 시도·자해 행동) 둘이다.
- 보건복지부 `q14`("죽고 싶다고 생각한 적이 있나요")는 평생 경험이라 은둔 74.9%, 고립 75.0%가 해당한다. 이 문항을 그대로 위기 기준으로 쓰면 고립·은둔 청년 4명 중 3명이 위기가 된다. 그래서 정의에 시점(지난 2주)을 넣고, 시점이 맞는 근거로 서울시 `B12_9`(PHQ-9 9번, 지난 2주)를 쓴다. "거의 매일"이 고립·은둔 18.3%, 전체 청년 4.4%다.
- 외부 근거: 보건복지부 고독사위기대응시스템(2026-02-27 개통)의 위기정보 27종에 자살고위험관리대상자와 내원사유 자해/자살 대상자가 포함된다. 27종은 고독사 위험군을 찾는 선별용 목록이라 전부 즉시 이관 기준은 아니다.

## 필요 지원 (`SUPPORT_TYPES`, `SUPPORT_NEED_PCT`)

보건복지부 필요 지원 문항(`q211`-`q2110`, 4점 척도)의 "매우 필요함" 비율을 쓴다(#19 3순위 규칙).

- "매우 필요함" 비율 순으로 고르면 21개 특징 모두 경제적 지원이 1위라 특징 간 구별이 없다. 경제적 지원은 고립·은둔 청년 전반의 기본 지원으로 보인다(은둔 60.5%, 고립 56.7%).
- 그래서 **특징 해당자의 비율이 전체 응답자(은둔+고립 합산)보다 높은 차이 순**으로 상위 3개를 고르고, `SUPPORT_NEED_PCT`에는 해당자의 실제 비율을 적는다.
- 결과 예: 정신건강·자살 관련 특징은 전문가 상담·치료, `ECON_NO_INCOME`은 취업·일 경험과 교육·학습, `SOLO_LIVING`은 혼자·같이 하는 취미 활동, `REL_LONELY`와 `MIND_SOCIAL_ANXIETY`는 머물 수 있는 공간이 상위다.
- 도움받지 않은 이유(`q20a1`)는 특징이 아니라 추천 문구 근거로 `risk_features_youth.csv`에 분포만 둔다(원하지 않아서 은둔 38.4%·고립 39.4%, 요청할 곳 몰라서 27.9%·28.3%).

## 병합 사전 (`data/processed/risk_feature_dictionary.csv`)

생성 코드: `uv run python -m src.features.risk_feature_dictionary`. 입력은 `data/interim/`의 `risk_feature_dictionary_youth.csv`, `risk_features_youth.csv`, `risk_features_senior.csv`다.

- **행:** 10/20에 확정한 21개 코드. 고령 12개는 모두 이 코드 안에 있다. 연령별로 다른 점은 범주를 나누지 않고 `AGE_PATTERN`에 적는다.
- **청년 값을 쓰는 열:** `FEATURE_NAME`, `DEFINITION`, `DETECT_DATA`, `IS_CRISIS`, `SUPPORT_TYPES`, `SUPPORT_NEED_PCT`. 정의는 10/20 확정본이고, `SUPPORT_NEED_PCT`는 실태조사 "매우 필요함" 비율이라 같은 문항이 없는 고령 지원 제안은 넣지 않는다(고령 제안은 `risk_features_senior.csv`).
- **연령대별로 잇는 열:** `AGE_PATTERN`, `EVIDENCE_SOURCE`, `EVIDENCE_VALUE`, `DETECT_RULE`. `[청년] … [고령·중장년] …` 형식이고, 고령 근거가 없는 9개는 `AGE_PATTERN`에 "A-2 근거 없음"으로 적는다.
- **비워 둔 열:** `INSTITUTION_TAGS`는 #18에서 채운다. A-2 태그 후보는 `feature_tag_mapping_a2_draft.csv`에 있다.
