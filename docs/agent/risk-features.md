# 고령·중장년 위험 특징 검토 (이슈 #17 A-2)

관련 이슈: [#17](https://github.com/Team-Hambugi-Lab/bigcontest-social-isolation/issues/17). **A-2 병합용 검토본**입니다. CSV·공식 PDF·검토 기록 파일은 별도 공유 묶음에 있으며, 문서 속 `data/`, `reference_sources/`, `review/` 경로는 해당 묶음 기준입니다. 드라이브 업로드·공유 링크는 이 문서 게시와 별도로 확인해야 합니다.

전체 검토 기록: [A-2 검토 보고서](../../reports/261020_issue17_a2_review.md).

검토 반영본 · 작성 기준: 2026-10-20, [이슈 #17](https://github.com/Team-Hambugi-Lab/bigcontest-social-isolation/issues/17)의 10/20 최종 수정.

## 전달할 결론

1. 청년 코드 이름을 참조한 **12개 A-2 특징 작업본**을 정리했다. A-1 실제 CSV의 문항·응답 코딩을 대조하기 전에는 의미까지 완전히 일치한다고 확정할 수 없다. 통계로 직접 확인된 내용, 정책상 근거, 팀의 운영 정의를 구분했다. 12개가 모두 고령층의 독립적 위험요인으로 검증되었다는 뜻은 아니다.
2. **BODY 유지**를 권한다. 건강 상태와 일상생활 기능은 하위 특징에서 구분할 수 있다.
3. 기본계획에는 위험군 선별 예시와 위험도 판단도구 개발 계획이 있지만, 검토 범위에서 **지난 2주 자살·자해 생각/행동을 즉시 위기로 정하는 기준은 확인되지 않았다.** 이를 정부 공식 기준으로 표현하지 않는다.
4. 도움 제공자 부재, 교류 빈도, 이동 수행 곤란의 **3개 신규 코드 후보**를 별도 파일로 제안한다. 팀 합의 전 확정 사전에 넣지 않는다.

## 범위·자료 확인

- S1 기본계획 PDF 44쪽 전체에서 고독사 정의, 위험군, 위기, 판단, 선별 관련 내용을 확인했다. 핵심 근거는 본문 p.14(PDF18), pp.16~18(PDF20~22), pp.25~28(PDF29~32).
- S2는 ‘2024년 조사’이지만 발생 대상은 **2022~2023년**이다. 2024년 발생분을 조사해 2025년에 발표한 자료와 구분한다. 전체 연령의 사망사례 특성을 고령·중장년 주민의 고립 유병률로 바꾸지 않았다.
- S3~S5는 **2023년 노인실태조사**에 기반하며 65세 이상을 설명한다. S1의 70대 이상 1인가구 위험군 결과와 합산하지 않는다. S3 전체 응답자는 10,078명이다.
- S4·S5는 조사 연구진이 집계한 원문 논문이다. 887쪽 전체 원보고서를 확인한 것으로 표현하지 않는다.
- 개인 응답 원자료는 사용·재배포하지 않았다. 지역 분석은 기존 산출물 정의와 S8의 실제 코드·보고서를 읽어 대조했다. 원자료와 드라이브 결과 CSV를 재실행·재계산하지 않았다. S9 태그 어휘·범주 매핑은 작업 브랜치에서 확인했다. A-1 실제 CSV와 노션 위험 특징 페이지는 현재 연결로 접근되지 않아 미확인이다.

## 특징표와 근거수치

- `data/interim/risk_features_senior.csv`: **12행 × 12열**(헤더 제외), 이슈 본문의 최종 사전 열 순서 유지. 기존 21개 코드 중 대응 가능한 12개만 작성했다.
- `data/interim/risk_features_senior_evidence.csv`: **22행 × 12열**, 지표별 원래 수치·단위·대상·기간·분모·출처.
- `data/interim/proposed_senior_features.csv`: **3행 × 7열**, 신규 코드 제안.
- 각 CSV의 `_dictionary.csv`는 열 설명이다. UTF-8 BOM은 엑셀 한글 열기를 위한 것이며 UTF-8과 호환된다.

### 결측과 미매핑

- `SUPPORT_NEED_PCT`는 전 행 공란이다. S1의 청소·세탁 11.5%, 외출동행 8.4%, 일자리상담 15.6%는 ‘매우 필요함’ 비율로 확인되지 않아 옮기지 않았다. 원래 수치는 근거 파일에 남겼다.
- `INSTITUTION_TAGS`는 **S9 범주 매핑을 상속한 후보**다. 최종 승인·무조건 추천 값이 아니다. `feature_tag_mapping_a2_draft.csv`의 39행에 출처 우선순위와 적용 조건을 기록했다. 일반 정신건강 어려움에 중독 태그를 자동 연결하거나, 고령이라는 이유로 치매 서비스를 연결해서는 안 된다. `SUPPORT_TYPES`는 지원 유형 제안이며 기관 서비스 태그와 다른 층이다.
- 제시되지 않은 고령 세부 문항의 비율을 청년 값으로 대체하지 않았다.

## BODY 범주 의견

**유지 의견이다.**

- 건강 상태: 주관적 건강, 질환, 장애와 생활 제약은 `BODY_POOR_HEALTH`에서 다루되 서로 다른 측정값임을 기록한다. S4 p.39~40(PDF3~4)은 주관적 건강과 만성질환을 별도 측정한다.
- 위생: `BODY_HYGIENE`에 세수·양치·목욕 등 ADL 수행을 연결한다.
- 생활공간 관리: `BODY_HOME_CARE`에 집안일·청소·세탁 등 IADL 수행을 연결한다.
- 이동·외출 수행 곤란은 `BODY_MOBILITY_LIMIT`를 후보로 제안한다. 활동에 참여하지 않는 OUT과, 수행능력에 제한이 있는 BODY를 구분할 수 있다.

S3 p.6(PDF6)의 기능 제한 **18.6%는 ADL 또는 IADL의 합친 값**이다. 위생 곤란 또는 청소 곤란의 비율로 복제하면 안 된다. 청년과 고령의 원인 차이는 AGE_PATTERN에 기록하면 된다. 따라서 HEALTH/LIFE로 상위 범주를 분리해야 할 직접적인 이유는 이번 검토에서 확인되지 않았다.

결론: 기본계획은 사회적 고립·생활지원 필요 위험군을 찾는 정책 근거로 쓸 수 있지만, 프로젝트의 즉시 사람 이관 기준 전체를 직접 검증하지는 않는다. ‘위기 가구’라는 표현의 출현 여부와 무관하게 **최근 2주 생각·행동을 기준으로 하는 운영 정의는 찾지 못했다.**

### IS_CRISIS 처리

- S7(팀 최종안)에 맞춰 `MIND_SUICIDE_IDEA`, `MIND_SUICIDE_ATTEMPT` 두 특징의 IS_CRISIS를 1로 두었다. 이는 **특징의 사람 이관 표시**이고, 특정 개인이 현재 즉각적 위험 상태라는 임상 판정값이 아니다.
- S4 p.41(PDF5)의 고령층 자살 생각 **1.0%는 지난 1년** 경험이다. 지난 2주 비율, 자해 생각까지 포함한 비율, 현재 위기 비율로 사용할 수 없다. 최근 시도·자해 행동의 동일 기간 고령 수치는 본 자료에서 확인하지 못했다.
- S6 NIMH 성인 후속평가 지침은 최근 생각의 빈도·마지막 시점, 현재 생각, 계획, 과거 행동 이력을 각각 확인한다. 따라서 팀의 2주 구분만으로 자동 응급도를 결정하거나, 2주 이전 시도 이력을 버리는 근거로 쓰지 않는다. 해당 평가는 훈련된 전문가의 역할이며 한국 서비스의 검증된 자동 규칙으로 제시하지 않는다.

S8의 기본 `tau=0.1`은 팀의 분석 선택값이며 검증된 개인 고립 임계값이 아니다. H4는 여러 연령대 산출물을 갖지만, 이번 A-2 연결은 60GU만 참조한다. 청년 대조 방향이 일관되지 않아 청년 OUT에 전용하지 않는다. 60GU는 60세 이상이며 S3~S5의 65세 이상과 연령 구간도 다르다.

`regional_feature_linkage.csv`에 #13의 6개 차원과 H4를 모두 대조했다. 노후주택·고령·중장년 남성에 직접 대응하는 특징 코드는 없다. 주거 대리지표의 범위와 분자 중복, 노출 지수의 유동과 H4 중복 반영을 #13·#16에서 조정해야 한다. 지역 지수의 차원·계수·점수를 이번 A-2 검토에서 임의 변경하지 않았다.

## 기존 코드에서 채우지 않은 항목

REL_NO_ADVICE, REL_FAMILY_CONFLICT, REL_NO_FAMILY, REL_LONELY, OUT_LONG_DURATION, SOLO_MEAL, BODY_SLEEP, MIND_HOPELESS, MIND_SOCIAL_ANXIETY의 **정확히 대응하는 고령 수치·문항**은 이번 범위에서 확보하지 못해 본표에 억지로 채우지 않았다. 고령층에 특징이 없다는 뜻은 아니다. 특히 하루 식사 1회는 혼자 식사 여부가 아니며, 연락 가능한 자녀 없음은 가족 전체가 없다는 뜻이 아니다.

## 통계 해석에서 제외한 항목

S2 p.10은 2023년 수급자 1,413명·41.4%를 함께 제시하지만, 1,413/3,661과 비율이 일치하지 않으며 해당 페이지에서 유효 분모를 명시적으로 확인하지 못했다. 따라서 이 비율을 본표의 핵심 정량 근거로 사용하지 않았다. 사망자 구성비·조사 응답 비율·지원 수요·문항 절단값을 각각 구분했다.

## 병합 시 남은 연결 작업

1. **A-1:** 실제 `risk_features_youth.csv`와 정의·응답 범주를 대조한다. OUT 무위 생활, ECON 주관적 경제 수준, HOUSE 두 거처 유형, REL 속마음 공유의 정확한 문항이 우선이다. `feature_merge_review.csv`에 12개 특징의 직접·관련 근거와 운영 상태를 적었다.
2. **#18:** 현재 39행은 범주 매핑 상속 초안이다. 조건·대상 연령·실제 서비스·운영 상태를 확인해 특징 단위 최종 매핑으로 확정한다. 지원 욕구 비율을 `SUPPORT_NEED_PCT`로 대체하지 않는다.
3. **#19:** OUT와 주관적 경제 수준의 개인 질문·기간·해당 응답을 확정한다. 은퇴·연금생활의 무소득활동, 신규 코드 분할이 특징 개수에 미치는 영향과 지원 비율 결측 시 정렬 정책을 정한다. 동의 거부·미응답은 0이나 위험으로 세지 않는다.
4. **#13·#16:** 사전 코드와 노출 차원, 유동 이중 반영, 제외·보류 상태를 맞춘다. 지역 신호는 개인 티어를 올리지 않는다.
5. **공유:** 근거 문서는 레포, CSV·열 설명은 드라이브에 배치하고 이슈에 실제 링크·행열수·생성 커밋을 남겨야 한다. 현재 산출물은 로컬 검토본이다. 신규 코드 3개는 팀 합의 전 채택하지 않는다.
