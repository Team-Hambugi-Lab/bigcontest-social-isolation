# 원본 데이터 안내

이 디렉터리에는 대회 제공 데이터와 외부 공공데이터의 원본을 저장합니다. 데이터 파일은 용량과 재배포 가능성 때문에 Git으로 추적하지 않으며, 이 안내 문서만 공유합니다.

## 팀 공유 원칙

1. 원본은 참가 팀원만 접근할 수 있는 공유 저장소에서 전달합니다.
2. 각 팀원은 공유받은 파일을 이 디렉터리에 같은 이름으로 배치합니다.
3. 원본은 수정하지 않습니다. 압축 해제본도 `data/raw/`에 둡니다.
4. 정제 결과는 `data/interim/`, 분석용 결과는 `data/processed/`에 생성합니다.
5. 외부 데이터는 출처, 내려받은 날짜, 원본 URL을 분석 문서에 기록합니다.

대회 약관의 데이터 공유·재배포 조건을 확인하기 전에는 원본 파일이나 다운로드 링크를 공개 저장소, 이슈 또는 PR에 올리지 않습니다.

## `src/data/` 코드를 쓰려면 — 로컬 폴더명 맞추기

`src/data/paths.py`는 SK·신한카드 원본이 아래 폴더명·형식으로 있다고 가정합니다.

```text
data/raw/
├── sk_telecom/
│   └── flow_{age,time,wkdy}_pop_{202507..202512}.csv   (콤마 구분, 18개)
└── shinhan_card/
    └── *.csv                                            (콤마 구분, 2개 — 이름 무관, 크기로 구분)
```

대회 원본은 SK가 파이프(`|`), 신한카드가 탭 구분이라 그대로는 안 맞습니다. 콤마로 변환한
사본을 저 이름의 폴더에 두거나(복사 또는 심볼릭 링크), 각자 변환 스크립트로 만들어 두세요.
원본 폴더(`2026빅콘테스트_..._레이아웃/`)는 그대로 유지하고 이 폴더들은 별도로 추가합니다.

예시(콤마 변환 사본이 이미 있는 경우, 심볼릭 링크로 연결):

```bash
mkdir -p data/raw/sk_telecom data/raw/shinhan_card
ln -s "$(pwd)/<콤마 변환 SK 폴더>"/*.csv data/raw/sk_telecom/
ln -s "$(pwd)/<콤마 변환 신한카드 폴더>"/*.csv data/raw/shinhan_card/
```

**다른 경로를 쓰는 코드도 있습니다.** `src/features/block_panel.py`·`risk_axes_v1.py`
(재언 위험지수 재현·검증 쪽)는 위 `sk_telecom/`이 아니라 `data/raw/sk_통신인구_{202507..
202512}_통합.csv`(age/time/wkdy 3테이블을 outer join으로 미리 합친 파일, `src/features/
build_sk_integrated.py`로 생성)를 직접 읽습니다. 둘 중 어느 쪽이 필요한지는 작업 중인
모듈이 어느 걸 import하는지로 확인하세요.

`src/data/external.py`의 `EXTERNAL_DIR`은 폴더명에 "SGIS"가 들어간 폴더를 `data/raw/` 아래에서
자동으로 찾습니다(`국가데이터처_SGIS 행정구역 통계 및 경계/`가 그대로 잡힙니다) — 별도로
`data/raw/external/`을 만들 필요는 없습니다. 이 폴더의 통계 CSV는 시도·시군구·행정동(8자리)
코드가 한 파일에 섞여 있는데, 로더가 8자리(행정동)만 자동으로 걸러 씁니다.

`src/features/block_panel.py`(집계구 공간조인)는 별도로 아래 두 shapefile이 필요합니다.

```text
data/raw/reference_data/강남_집계구경계/bnd_oa_11230_2025_2Q.shp
data/raw/reference_data/춘천_집계구경계/bnd_oa_32010_2025_2Q.shp
```

집계구(14자리 `TOT_OA_CD`) 단위 인구 통계가 필요하면 `reference_data/집계구_통계자료/`를
씁니다 — 단 가구·1인가구 통계는 여기 없고 `행정안전부_주민등록_거주통계/`(행정동 단위)에서
가져와야 합니다.

## 무결성 확인

macOS와 Linux에서 다음 명령으로 공유받은 ZIP 파일이 동일한지 확인합니다.

```bash
shasum -a 256 data/raw/*.zip
```

표의 SHA-256 값과 다르면 분석에 사용하지 말고 파일을 다시 전달받습니다.
