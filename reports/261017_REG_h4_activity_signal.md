## 2. 신호 기준 τ 결정 (2026-10-18)

- 재현: `uv run python -m src.modeling.h4_activity_signal` (진단 `data/interim/h4_model_diagnostics.csv`, 민감도 `data/interim/h4_sensitivity.csv`)
- 신호: 6개월 중 `RESID < −τ`인 달이 4개월 이상이고 평균 잔차도 `−τ` 미만. `RESID = log(실제/기대)`이므로 `τ = 0.1`은 기대보다 약 10%(e^−0.1 ≈ 0.905) 낮다는 뜻이다.

### 분석 결과

**핵심 발견:**
- **계획대로 `τ = 0`이면 판정 집계구의 약 절반이 신호다.** 잔차가 집계구마다 거의 고정이라(ICC 0.92~0.97) 신호가 사실상 "평균 잔차 하위 절반"이 된다.
- **0.1 이상이면 우연한 달별 흔들림보다 충분히 크다.** 60대 이상의 달별 흔들림은 중앙값 0.02라서, 이 기준으로는 0.1·0.2·0.3을 가를 수 없다.
- **행정동 구분은 0.1이 낫다.** 60대 이상에서 `τ = 0.2`면 47개 동 중 23곳이 신호율 0%로 같아진다. `τ = 0.1`이면 16곳이다.

**수치 요약 (60대 이상):**

| 지표 | 값 |
|------|-----|
| 월별 잔차 ICC | 0.971 |
| `N_LOW_MONTHS`(τ = 0) 분포 | 0개월 587곳, 6개월 631곳, 1~5개월 186곳 |
| 같은 집계구 달별 잔차 표준편차 (중앙값 / 90%) | 0.020 / 0.061 |
| 집계구 간 평균 잔차 표준편차 | 0.233 |

**해석:** τ는 "얼마나 낮아야 낮다고 볼까"의 선이다. 우연한 흔들림과 비교하면 0.1 이상은 모두 의미 있는 차이라서, 남은 선택 기준은 쓰임새다. 결과를 행정동 우선순위에 쓰므로 동 사이 차이가 남는 0.1을 기본으로 정했다. 0.1은 데이터로 하나로 정해지는 값이 아니라 판단값이며, 0·0.2·0.3을 민감도로 함께 보고한다.

**권장 다음 단계:** 행정동 우선순위는 `τ = 0.1`의 `SIGNAL_RATE`, 0.2·0.3에서도 남는 동, `DONG_POOLED_RESID`를 함께 보고 정한다.

- 재현: `uv run python -m src.evaluation.h4_external_validation` → `data/interim/h4_external_validation.csv`
- 자료: 서울 1인가구 통신정보(2025-07~12), 강남 22개 행정동. 동 × SK 연령대마다 성·5세 연령·월을 총인구수로 가중 평균했다.

### 분석 결과

**핵심 발견:**
- **60대 이상은 8개 대조 모두 예상한 방향이다.** `SIGNAL_RATE`가 높은 동일수록 고령 1인가구의 집 체류시간이 길고(ρ = 0.438~0.509) 이동 횟수가 적다(ρ = −0.493~−0.601).
- **20대는 반대 방향이 섞여 있다.** 신호율이 높은 동일수록 평일 이동 횟수가 **많다**(ρ = 0.533, p = 0.011). 20대에서 기대보다 낮은 동네 유동은 활동 저하보다는 **다른 동네로 나가 있음**(출퇴근·통학)을 반영하는 것으로 보인다.
- **30대는 일관된 방향이 없다.** 8개 중 1개만 예상 방향이다.

**수치 요약 (60대 이상, 22개 동, Spearman):**

| 대조 지표 | `SIGNAL_RATE` ρ (p) | `DONG_POOLED_RESID` ρ (p) |
|------|------|------|
| 집 체류시간 평일 | 0.509 (0.016) | −0.248 (0.266) |
| 집 체류시간 휴일 | 0.438 (0.042) | −0.215 (0.336) |
| 이동 횟수 평일 | −0.601 (0.003) | 0.394 (0.070) |
| 이동 횟수 휴일 | −0.493 (0.020) | 0.251 (0.259) |

| 연령대 | 예상 방향과 일치한 대조 (8개 중) |
|------|------|
| 60대 이상 | 8 |
| 50대 | 8 |
| 20대 | 4 |
| 30대 | 1 |
| 40대 | 0 |

**해석:** 60대 이상에서는 "기대보다 낮은 유동 = 집에 머물고 덜 움직임"이라는 가정이 강남 1인가구 자료와 맞는다. `SIGNAL_RATE`가 `DONG_POOLED_RESID`보다 대조 지표와 더 강하게 맞는다. 반면 20~30대에서는 같은 신호가 다른 것(외출해서 동네에 없음)을 잡는 것으로 보인다. 따라서 **이 신호는 60대 이상의 고립 위험 근거로 쓰고, 20~30대에는 그대로 쓰지 않는다.**

**권장 다음 단계:** 20~30대 신호는 발표에서 "활동 저하"로 표현하지 않는다. 쓰려면 출퇴근 영향을 더 걸러야 한다(예: 주간 유동 대신 야간·주말 유동). #17의 청년 쪽 `OUT` 감지 근거로는 쓰지 않는다고 팀에 공유한다.

- **주의:** 동이 22개뿐이고, 대조 자료는 1인가구만이며 강남만 있다. 60대 이상 8개 대조에 다중비교 보정(Bonferroni 0.05/8 = 0.006)을 하면 평일 이동 횟수(p = 0.003)만 유의하다. 방향의 일관성(8/8)이 개별 p값보다 강한 근거다.
- 동 단위 상관이므로 개인이 집에 머문다는 뜻이 아니다(생태학적 오류).

**해석:** 노출 지수는 "누가 사는가", 활동 신호는 "실제로 얼마나 움직이는가"를 본다. 둘의 관계가 지역마다 반대라서 하나의 점수로 합치면 어느 쪽 정보도 제대로 남지 않는다. 그래서 두 값을 나란히 두고, 에이전트에는 "관찰 후보이면서 신호", "신호로만 판단", "사각지대"를 따로 넘긴다. 업무지가 섞인 동(역삼1·논현1·논현2·대치4동 등)의 신호는 고령 활동 저하로 단정하지 않는다.

**권장 다음 단계:** 우선 대상 행정동을 고르는 기준(예: 관찰 후보이면서 신호인 집계구 수, 사각지대 비중)을 팀에서 정한다. 업무지 혼합 동은 `mixed`·`work_ratio`로 따로 표시하는 것을 검토한다.

## 8. 한계

- **지역 신호이지 개인 판정이 아니다.** 결과는 우선 지원 지역·계층과 관찰 빈도를 정하는 데 쓴다.
- **수준 차이이지 추세가 아니다.** 거주 인구가 2024년 값 하나이고 잔차 ICC가 0.92~0.97이다. "기대보다 낮은 상태가 지속된다"로 쓰고 "감소한다"로 쓰지 않는다.
- **거주 인구(SGIS 2024)와 유동(SK 2025-07~12)의 시점이 다르다.**
- **SK 유동의 정의를 공식 확인하지 못했다.** 집에 있는 사람은 거의 세지 않는 것으로 보인다(1.1절). SK 「10대」가 10~19세인지도 확인하지 못했다.
- **유동에는 다른 동네에서 온 같은 연령대 방문자가 섞인다.** 20~30대에서 신호 방향이 맞지 않는 이유로 보인다(6절).
- **외부검증은 강남 22개 동, 1인가구만이다.** 춘천은 대조 자료가 없다.
- **신호 기준 τ = 0.1은 판단값이다**(2절). 민감도로 0~0.3을 함께 보고한다.
- **노출 지수와의 결합은 단면 비교다.** 지수(SGIS 2024)와 신호(SK 2025 하반기) 모두 한 시점 값이라 인과를 말할 수 없다. 춘천의 반대 방향은 원인을 확인하지 못했다(7절).
- **결합 결과도 지역 우선순위용이다.** 지수 백분위·등급은 강남·춘천 각각의 내부 순위이고, 개인 위험 티어를 올리는 근거로 쓰지 않는다.
