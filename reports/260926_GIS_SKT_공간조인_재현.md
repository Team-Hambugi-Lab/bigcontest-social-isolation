# SKT 좌표-행정구역 공간 조인 재현 정보

## 목적

2025년 7월 SKT 성·연령 유동인구 지점을 서울 강남구와 강원 춘천시 경계에 매핑한 과정과 결과를 재현한다.

## 사용 데이터

### SKT 분석 입력

- 파일: `sk_통신인구_202507_통합.csv`
- 분석 대상: 12개 성·연령 지표가 모두 존재하는 행
- 지점 식별 기준: `STD_YM`, `BLOCK_CD`, `X_COORD`, `Y_COORD`
- 지점 수: 98,129개
- 해당 분석 입력에서 좌표 중복: 0개

### 행정구역 경계

- 데이터명: 국가데이터처_SGIS 행정구역 통계 및 경계_20250630
- 출처: https://www.data.go.kr/data/15129688/fileData.do
- 사용 파일: `bnd_sigungu_00_2025_2Q.*`
- 경계 기준일: 2025-06-30 (`BASE_DATE=20250630`)
- 사용 지역: 강남구(`SIGUNGU_CD=11230`), 춘천시(`SIGUNGU_CD=32010`)
- 원본 및 분석 좌표계: EPSG:5179

SHP는 `.shp`, `.shx`, `.dbf`, `.prj`, `.cpg`가 함께 있어야 한다. 원본 파일은 크기가 크므로 팀 Google Drive의 `data/raw/reference_data/sgis_boundary_2025_2Q/`에 동일한 이름으로 보관한다.

## 공간 조인 방법

- 포인트 생성: `X_COORD`, `Y_COORD`
- SKT 포인트 좌표계: `EPSG:5179`
- 경계 좌표계: `EPSG:5179`
- 공간 조건: `intersects`
- 조인 대상: 강남구·춘천시 경계만 사용
- `BLOCK_CD` 앞자리로 지역을 추정하지 않음

`intersects`를 사용한 이유는 경계선 위에 위치한 포인트도 포함하기 위해서다. 두 대상 지역은 서로 떨어져 있으므로 하나의 포인트가 두 지역에 중복 배정되는지 별도로 검증한다.

## 2025년 7월 결과

| 구분 | 지점 수 |
|---|---:|
| 전체 분석 지점 | 98,129 |
| 강남구 경계 안 | 15,249 |
| 춘천시 경계 안 | 82,818 |
| 두 지역 경계 밖 | 62 |
| 매핑 성공률 | 99.9368% |

## 경계 밖 62개 처리

- 강남구·춘천시 지역 집계에서는 제외한다.
- 가장 가까운 행정구역으로 강제 배정하지 않는다.
- 원인 확인과 재현을 위해 `202507_경계밖_62개.csv`로 별도 보존한다.
- 원본 행은 삭제하거나 0으로 대체하지 않는다.

## 실행 방법

재현 노트북 `notebooks/260926_GIS_skt_spatial_join_jhj.ipynb`을 실행한다. 노트북은 다음 위치를 우선 탐색한다.

1. 환경변수 `BIGCONTEST_ROOT`로 지정한 프로젝트
2. 노트북 실행 디렉터리
3. `~/Desktop/빅콘 공모전`

팀 저장소에서는 다음 구조를 권장한다.

```text
data/
├── processed/
│   └── sk_월별_통합/
│       └── sk_통신인구_202507_통합.csv
└── raw/
    └── reference_data/
        └── sgis_boundary_2025_2Q/
            ├── bnd_sigungu_00_2025_2Q.shp
            ├── bnd_sigungu_00_2025_2Q.shx
            ├── bnd_sigungu_00_2025_2Q.dbf
            ├── bnd_sigungu_00_2025_2Q.prj
            └── bnd_sigungu_00_2025_2Q.cpg
```

노트북 결과는 Git 추적 대상이 아닌 `data/processed/skt_spatial_join_202507/`에 저장된다.
